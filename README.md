# 小游戏项目

这是独立发布的完整小游戏项目，收纳宠物积分系统的全部游乐场玩法、经典 12 场景森林冒险、三世界故事地图、261 种宠物卡牌与完整单词地图词库。它和单词远征不同：单词远征按学习阶段开放少量内容，本项目直接提供完整地图、完整玩法和全量词库。

当前游戏库包含学习机游乐场、消灭苦力怕、单词像素探险、森林冒险、三世界故事地图、数学 PK、汉字挑战、宠物卡牌图鉴和卡牌训练营，同时保留汉字泡泡跑酷与拼音星际巡航两个轻量入口。

## 本地运行

```powershell
npm run serve
```

默认地址：`http://127.0.0.1:7003/`

游戏进度只使用本项目自己的存储命名空间。由宠物积分总站启动时，URL hash 可携带 `petbankLaunch` 和 `petbankProfile`；游戏结束后只回传完成事件，成长积分仍由主站统一结算。

生产发布地址：`https://nonomil.github.io/mini-games/`
