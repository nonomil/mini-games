# 01 核心循环与用户旅程

## 1. 主循环

```text
进入农场
  -> 看到今日推荐任务
  -> 选择 3-8 个目标词
  -> 在地图中探索并完成学习动作
  -> 获得种子、能量、装饰或伙伴碎片
  -> 播种并照料
  -> 离开游戏，成长继续
  -> 再次进入时收获
  -> 用收获升级农场，并复习上次不稳定的词
```

## 2. 学习动作与游戏动作的关系

学习不能只出现在弹窗中。每种学习行为都要对应一个游戏结果：

| 学习动作 | 游戏表现 | 结果 |
| --- | --- | --- |
| 看图片、听发音 | 发现新的种子或 NPC | 建立第一次接触 |
| 选择中文含义 | 拾取正确颜色的种子 | 引导式回忆 |
| 根据中文找英文 | 击中对应敌人或开启宝箱 | 主动回忆 |
| 拼写或键盘输入 | 加速机器、修复飞船 | 更强主动回忆 |
| 延迟后再次回忆 | 收获成熟作物 | 检查长期保持 |

## 3. 首次 5 分钟

首次进入不要先展示全部系统。推荐流程：

1. 选择一个角色，地图默认进入森林农场。
2. 玩家看到一块空地和一个会说话的伙伴。
3. 伙伴给出 3 个入门词，例如 `tree`、`bird`、`water`。
4. 玩家先听、再选、再在短局中使用其中一个词。
5. 完成后获得第一颗种子，点击播种。
6. 看到作物进入第一阶段，提示“离开后也会继续成长”。
7. 页面给出两个下一步按钮：“继续探索”与“去太空农场看看”。

角色选择、地图选择和词包选择可以之后再细调，不要让新用户在第一分钟连续做三次设置。

## 4. 单局结构

一局控制在 3-8 分钟：

- 开始：显示本局 3-5 个目标词。
- 中段：每完成一个词就出现可见的地图反馈。
- 结束：给出学习报告、收获和下一次复习时间。
- 失败：只消耗时间或护盾，不清空作物和长期进度。

## 5. 离开与回来

玩家离开时保存：

- 当前农场、地块和作物状态。
- 作物种下时间、成长阶段和照料加成。
- 当前学习局的已见词、正确次数和错词。
- 未领取的奖励和下一次复习时间。

重新进入时优先展示“继续上次”和“收获 2 块地”，而不是直接回到游戏目录。
