# 07 移动端交互与视觉规范

## 1. 移动端优先

参考项目强调“手机浏览器打开就能玩”，当前单词地图需要补齐：

- 点击地面移动，长按持续移动。
- 左下角虚拟方向盘或圆形摇杆。
- 右下角固定动作按钮：互动、拾取、提示、朗读。
- 所有可点目标最小触控区域建议 44px。
- 游戏场景使用 `100dvh` 和安全区，避免被手机地址栏和刘海遮挡。
- 游戏区域使用 Pointer Events，并为自定义拖动区域设置合适的 `touch-action`。

保留键盘 WASD、方向键和数字键，不要让桌面端退化。

## 2. 统一 HUD

主界面只保留四项高频信息：

1. 当前目标词进度。
2. 当前资源或护盾。
3. 当前农场和返回入口。
4. 一个主要动作按钮。

词包、地图、分类、声音、关卡等低频设置放入可折叠面板。当前 `games/word-memory-map/index.html` 的 HUD 控件较多，移动端应减少同时出现的选择器。

## 3. 像素视觉规则

当前验证图中存在高分辨率背景与小尺寸像素角色、黑色单词标签和卡通炸弹混用的情况。建议制定最小视觉规范：

- 每张地图使用固定的 12-16 色主调。
- 背景、角色、敌人、道具统一描边和阴影方向。
- 词语标签使用同一套字号、圆角和对比度。
- 地图物件的底部锚点一致，避免角色像漂浮在地面上。
- 重要目标使用动画或高亮，不只依赖颜色。
- 手机窄屏优先保证词语可读，不为了展示大背景而缩小文字。

## 4. 反馈节奏

- 答对：目标高亮、短音效、局部粒子、奖励飞向 HUD。
- 答错：轻微震动、正确词卡、短提示，不做大面积失败遮罩。
- 收获：作物变化、数字递增、伙伴反应。
- 新地图：只展示一次地图名和一个目的，不连续弹三层介绍。

## 5. 无障碍和低刺激选项

- 支持关闭闪烁、音效和背景动画。
- `prefers-reduced-motion` 下保留信息反馈，减少位移和缩放。
- 文字与背景保持足够对比度。
- 语音按钮需要清楚标识当前词，而不是只显示抽象图标。
