# 09 实施路线与验收指标

## P0：先让它像一个能持续玩的游戏

1. 建立世界入口：森林农场、太空农场、外星农场三张卡片，显示主题、推荐词包和当前成长。
2. 增加“继续上次”入口，保存当前局、地块和未领取奖励。
3. 为单词地图加入点击地面移动和虚拟方向盘。
4. 将首次加载改成 starter/core，all 词库和大地图资源按需加载。
5. 统一三张地图的资源、作物、NPC、活动配置格式。
6. 为三张地图定义统一的探索路线节点、恢复上下文和活动返回协议。

验收：手机 360x800 可以从打开页面到完成第一株作物；刷新或重新打开后，作物和学习局状态仍在。

## P1：完成森林农场垂直切片

1. 4 块地、6 种作物、1 个 NPC、1 个商店、1 个学习屋。
2. 3 个 starter 词 + 6 个 core 词形成完整学习循环。
3. 单词探险屋完成一局后必定产生种子或照料资源。
4. 词卡提供发现、引导回忆、主动回忆、延迟复习四个证据。
5. 收获结果页同时展示游戏奖励和学习报告。
6. 完成森林入口、学习屋、溪流、探险屋、农场和区域检查点的一条 RPG 路线。

验收：新用户 5 分钟内能理解为什么要学习、为什么要回到农场；家长能看到错词和下次复习时间。

## P2：加入太空农场

1. 用温室、能源、维修机器人替换森林的水滴、植物和向导。
2. 接入打字防守和拼音赛车作为活动建筑。
3. 增加核心英语和科技主题词包。
4. 增加轨道昼夜和能源动画，但不影响可玩性。
5. 将苦力怕和飞机大战作为维修通道、飞行训练站活动接入，结束后返回原节点。

验收：太空农场不是换背景，玩家能说出它的资源、角色和学习目标与森林不同。

## P3：加入外星农场

1. 接入拓展词、Minecraft 词和错词复习池。
2. 增加变异作物和晶体稳定度。
3. 增加传送门、异星商人和一条轻量故事线。
4. 用高阶奖励鼓励复习，不用更严厉的失败惩罚。
5. 增加由错词和到期卡驱动的遗迹路线与待补强区域挑战。

语法之塔、海洋和天空地图属于后续扩展；没有独立语法/表达内容包时，不把普通单词题包装成语法关卡。详细设计见 [RPG 探索地图与闯关方案](./11-RPG探索地图与闯关方案.md)。

## 指标建议

### 游戏体验

- 首次可操作时间：中端手机 4G 网络目标小于 3 秒。
- 首次启动传输量：不含延迟资源目标小于 5 MB 压缩后。
- 首次 5 分钟完成率：目标不低于 70%。
- 单局中途退出后恢复成功率：目标不低于 99%。
- 移动端关键触控区域误触率：目标低于 5%。

### 学习质量

- 每个新词至少产生一次主动回忆证据。
- 每次会话至少复习 2 个到期或错词。
- 记录提示使用次数，避免把看答案误算为完全掌握。
- 用次日和第 7 天的小样本复测观察保持率。

### 内容质量

- 每张地图至少有 1 个可识别 NPC、1 个独特资源、1 个独特活动。
- 每种作物有四阶段视觉变化。
- 同一张词卡在不同题型中的答案、发音、释义保持一致。

## 验证命令

```powershell
npm test
npm run build:static
npm run serve
```

现有测试主要验证 manifest、完整内容模式、素材路径和运行时契约；新增功能后应补浏览器级移动端测试，覆盖首次进入、触摸移动、种植、刷新恢复、错词复习和跨地图返回。
