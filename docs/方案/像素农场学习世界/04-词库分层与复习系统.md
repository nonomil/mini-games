# 04 词库分层与复习系统

## 1. 词库不是地图列表

地图、主题和难度是不同维度：

- 地图主题：森林、太空、外星。
- 词汇主题：动物、植物、交通、科技、Minecraft 等。
- 学习阶段：入门、核心、拓展、复习。
- 题型能力：识别、听辨、回忆、拼写、使用。

一张词卡可以同时属于多个主题，但只保留一个稳定 ID。

## 2. 推荐词包

| 词包 | 规模 | 适用场景 | 首次加载 |
| --- | ---: | --- | --- |
| starter | 30-60 | 首次 5 分钟和森林农场教学 | 立即加载 |
| core | 300-500 | 森林主线、太空农场基础 | 按主题加载 |
| extension | 500-1000 | 太空挑战和外星农场 | 用户选择后加载 |
| all | 3000+ | 完整内容和自由探索 | 后台或按需加载 |
| review | 动态 | 当前玩家的错词和间隔复习 | 优先加载 |

当前项目已有 core、extension 和 all 运行词库，方案只要求增加统一索引和按需加载，不要求重新制作全部词卡。

## 4. 复习间隔

初版可以采用简单、可解释的间隔：

```text
首次接触 -> 立即重试 -> 次日 -> 第 3 天 -> 第 7 天 -> 第 14 天 -> 第 30 天
```

答错时缩短间隔，但不删除已获得的作物和装饰。答对但使用提示时只推进一小步，独立答对才推进完整熟练度。

## 5. 每次只处理一个小池

即使全部词库开放，也不要让一局从 3000 多张词卡随机抽取。推荐：

- 一次会话：3-8 个新词 + 2-4 个复习词。
- 一张地图：按主题池抽取。
- 一次失败：保留目标词，降低难度，不立即换一批词。
- 一次完成：显示下次复习时间和错词预览。
