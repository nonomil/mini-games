# 像素农场学习世界执行计划

这套计划用于后续逐项推进“森林农场、太空农场、外星农场”统一世界改造。

## 使用顺序

1. 先读 [00-总执行计划](./00-总执行计划.md)，确认阶段和依赖。
2. 按 [09-推进状态](./09-推进状态.md) 中的 `Next Task` 开始。
3. 执行任务文件里的 Files、Steps 和 Acceptance，不跨阶段提前堆功能。
4. 每个任务完成后，在状态文件中记录结果、测试命令和遗留问题。
5. 阶段结束必须通过 [08-验收矩阵](./08-验收矩阵.md) 对应的 Gate，才进入下一阶段。

## 任务编号

| 前缀 | 范围 |
| --- | --- |
| P0 | 共享底座、存档、输入、首屏和世界入口 |
| P1 | 森林农场第一条完整可玩的垂直切片 |
| P2 | 太空农场及科技/打字学习活动 |
| P3 | 外星农场、错词复习和变异成长 |
| L | 学习机制和词库独立任务 |
| X | 跨阶段工程、性能、移动端和质量任务 |

## 当前执行结论

- 先做一张完整的森林农场，再复制配置扩展到太空和外星。
- 所有地图保持完整内容可进入，任务采用推荐路线，不做硬锁。
- 不把 `word-memory-map`、`learning-arcade` 等已有入口重写成新引擎。
- 每个游戏动作都必须能解释为学习证据、世界成长或两者之一。

## 常用命令

```powershell
npm test
npm run test:contract
npm run test:complete
npm run serve
```

当前仓库没有 Git 元数据，因此计划中的“提交”先按任务检查点记录；后续若加入 Git，再使用任务 ID 作为提交前缀。
