## 状态枚举

- `ready`：依赖满足，可以开始。
- `in_progress`：正在修改任务文件。
- `blocked`：依赖、资源或外部选择未满足，必须写明原因。
- `review`：实现完成，等待验收矩阵。
- `done`：自动化和手工验收均通过。

## 更新规则

每次推进只允许更新一个 Current Task。完成任务后追加：

```text
### YYYY-MM-DD Task ID
Status: done | blocked
Changed: ...
Verified: ...
Manual: ...
Known Risk: ...
Next: ...
```

不得为了让状态看起来完成而跳过 Gate、删除失败测试或放宽完整内容契约。
