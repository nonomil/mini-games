# 05 P3 外星农场

P3 面向已经有一定词汇量的玩家，重点是错词复习、拓展词和变异成长，不通过更强惩罚制造难度。

## P3-01 外星世界配置

**Depends:** P2 Gate

**Files:**

- Create: `data/worlds/alien-farm.json`
- Create: `data/worlds/alien-scenes.json`
- Create: `data/worlds/alien-npcs.json`
- Modify: `data/worlds/manifest.json`

**Acceptance:** 配置异星商人、翻译虫、传送门、晶体作物和 review/minecraft/extension 词池。

## P3-02 变异作物和晶体稳定度

**Depends:** P0-02、P3-01

**Files:**

- Create: `data/crops/alien.json`
- Modify: `vendor/js/world-state.js`
- Modify: `games/word-memory-map/game.js`
- Create: `tests/test-alien-mutation.mjs`

**Steps:**

1. 复习错词增加晶体稳定度。
2. 独立答对旧词时增加变异品质。
3. 提示后答对只保留基础变异，不完全阻止收获。
4. 稳定度达到阈值后改变作物外观和奖励。

**Acceptance:** 变异是可解释的学习反馈；错词不会导致作物死亡；重复刷新不能重复生成变异奖励。

## P3-03 复习农场

**Depends:** P0-03、P3-02

**Files:**

- Create: `vendor/js/review-garden.js`
- Modify: `games/word-memory-map/game.js`

**Acceptance:** 外星农场能读取到期词、错词和最近提示词；一次复习会话不超过 12 张卡；完成后正确更新 `dueAt`。

## P3-04 异星故事和传送门

**Depends:** P3-01、P3-02

**Files:**

- Modify: `vendor/js/pixel-story-engine.js`

**Acceptance:** 至少 5 个短事件串联到变异农场；事件中出现的词卡来自当前词池；全部节点仍可自由选择。

## P3-05 P3 Gate

**Acceptance:** 外星农场完成一次错词复习即可改变至少一块地的视觉或状态；返回森林和太空时共享词卡进度和背包；不存在每日次数硬限制。
