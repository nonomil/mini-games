# 03 P1 森林农场垂直切片

P1 只做一张完整地图，不追求内容数量。目标是验证“学习 -> 获得资源 -> 种植 -> 离开 -> 回来收获”的闭环。

## P1-01 森林农场地图壳

**Depends:** P0 Gate

**Files:**

- Modify: `games/word-memory-map/game.js`
- Modify: `games/word-memory-map/game-data.js`
- Modify: `games/word-memory-map/styles.css`
- Create: `data/worlds/forest-farm.json`
- Create: `data/worlds/forest-scenes.json`

**Steps:**

1. 建立入口区、田地区、学习屋、商店和传送门五个区域。
2. 将主题、背景、可交互物件从代码移动到配置。
3. 保留当前单词探险战斗和关卡作为森林农场主活动。
4. 增加可见的地图状态：空地、成长中、成熟和待复习幼苗。

**Acceptance:** 进入森林后五个区域可见；地图切换不破坏原有单词目标和投掷逻辑。

## P1-02 地块、作物和收获

**Depends:** P0-02、P1-01

**Files:**

- Create: `data/crops/forest.json`
- Modify: `vendor/js/world-state.js`
- Modify: `games/word-memory-map/game.js`
- Modify: `games/word-memory-map/styles.css`
- Create: `tests/test-forest-crops.mjs`

**Steps:**

1. 配置 4 块地和 6 种作物，覆盖快速、标准、长线三档。
2. 为每种作物配置四阶段素材和收获奖励。
3. 增加播种、照料、查看成长和收获按钮。
4. 将正确学习行为转换为水滴或成长加速，不让水滴变成强制任务。
5. 将收获结果写入背包和星星奖励。

**Acceptance:** 4 块地可以独立种植；成熟作物可收获一次且不会重复发奖；离线时间正确推进。

## P1-03 学习屋与 starter 词池

**Depends:** P0-03、P0-06

**Files:**

- Create: `data/learning/starter-forest.json`
- Modify: `games/word-memory-map/index.html`
- Modify: `games/word-memory-map/game.js`
- Create: `vendor/js/learning-house.js`
- Create: `tests/test-starter-pack.mjs`

**Steps:**

1. 选取 30-60 张低难度自然、动物、植物词卡。
2. 学习屋提供图片、发音、中文和例句，不直接发放完整奖励。
3. 记录发现、听辨和主动回忆三类证据。
4. 一次会话只抽取 3-8 个目标词和 2-4 个复习词。

**Acceptance:** 词卡字段完整；未加载 all 词库时学习屋仍可使用；每个目标词至少有一次主动回忆入口。

## P1-04 单词探险奖励桥接

**Depends:** P1-02、P1-03

**Files:**

- Modify: `games/word-memory-map/game.js`
- Modify: `vendor/js/learning-memory.js`
- Modify: `vendor/js/world-state.js`
- Create: `tests/test-learning-reward-bridge.mjs`

**Steps:**

1. 独立答对时发放完整水滴和种子概率。
2. 使用提示后答对时只发放基础奖励并缩短复习间隔。
3. 答错时加入错词队列并显示正确发音，不删除作物。

**Acceptance:** 游戏奖励与学习证据一一对应；重复点击同一目标不能重复发奖；bridge 完成事件仍只发送一次。

## P1-08 P1 Gate

**Manual script:**

1. 新用户进入森林农场。
2. 完成 3 个 starter 词的发现、听辨和主动回忆。
3. 获得种子并播种。
4. 离开页面，等待快速作物成熟，再回来收获。
5. 故意答错一个词，确认它进入复习队列但不丢失作物。
6. 切换太空农场，再返回森林确认状态仍在。

**Acceptance:** G1 必须同时满足学习闭环、农场闭环、存档闭环和移动端闭环。
