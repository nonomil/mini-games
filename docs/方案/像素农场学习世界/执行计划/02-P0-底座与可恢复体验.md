# 02 P0 底座与可恢复体验

P0 的目标是让用户能从入口进入任意主题农场，完成一小段操作，刷新后继续，并能在手机上移动。

## P0-01 世界数据契约

**Depends:** 无

**Files:**

- Create: `data/worlds/manifest.json`
- Create: `data/worlds/forest-farm.json`
- Create: `data/worlds/space-farm.json`
- Create: `data/worlds/alien-farm.json`
- Modify: `data/manifest.json`
- Test: `tests/test-world-contract.mjs`

**Steps:**

1. 为三张主地图定义 `id/title/theme/recommendedPacks/cropSet/npcSet/activities/background`。
2. 规定所有地图都为 `mode: complete`，不引入 staged 锁定字段。
3. 在 `data/manifest.json` 增加世界配置入口，不复制现有游戏入口。
4. 测试每个世界的活动入口、背景和词包引用都存在。

**Acceptance:** `node tests/test-world-contract.mjs` 通过；三张地图均能从数据层读取，不依赖硬编码的 if/else 分支。

## P0-02 世界状态与离线成长

**Depends:** P0-01

**Files:**

- Create: `vendor/js/world-state.js`
- Create: `data/crops/manifest.json`
- Create: `data/crops/forest.json`
- Create: `tests/test-world-state.mjs`
- Modify: `games/word-memory-map/game-storage.js`

**Steps:**

1. 定义地块状态：`plotId/cropId/plantedAt/lastWateredAt/growthBonusSeconds/state`。
2. 实现纯函数 `getGrowthState(crop, plot, now)`，不读取 DOM。
3. 实现 `plantCrop`、`applyGrowthBonus`、`harvestCrop`，禁止作物倒退或因离线死亡。
4. 用版本号保存世界状态，读取旧版本时返回空世界而不是抛异常。
5. 为 60 秒、10 分钟、24 小时和超时场景写测试。

**Acceptance:** 时间计算测试通过；刷新页面后作物阶段一致；非法时间跳变不会产生负成长或无限奖励。

## P0-03 词卡学习状态

**Depends:** 无，可与 P0-02 并行

**Files:**

- Create: `vendor/js/learning-memory.js`
- Create: `data/learning/review-policy.json`
- Create: `tests/test-learning-memory.mjs`

**Steps:**

1. 定义 `new/learning/review/stable/mastered` 状态。
2. 记录 `hintCount/correctStreak/lastSeenAt/dueAt/evidence`。
3. 实现 `recordEvidence(cardId, evidenceType, result, now)`。
4. 按立即、次日、第 3 天、第 7 天、第 14 天计算下一次复习。
5. 将提示后答对与独立答对区分奖励等级。

**Acceptance:** 同一词卡的识别、听辨、回忆、拼写证据独立累计；错词缩短复习间隔但不删除世界奖励。

## P0-04 统一移动输入

**Depends:** 无，可与 P0-02 并行

**Files:**

- Create: `vendor/js/world-input.js`
- Create: `tests/test-input-contract.mjs`
- Modify: `games/word-memory-map/game.js`
- Modify: `games/word-memory-map/styles.css`
- Modify: `games/word-memory-map/index.html`

**Steps:**

1. 抽象 `setDirection`、`clearDirection`、`setPointerTarget`。
2. 使用 `pointerdown/pointermove/pointerup/pointercancel` 支持触摸、鼠标和手写笔。
3. 增加点击地面移动和左下角虚拟方向盘。
4. 在移动区域设置 `touch-action`，不阻止页面其他区域的缩放和辅助功能。
5. 保留 WASD、方向键和原有点击目标行为。

**Acceptance:** 360x800 可单手完成移动、拾取、选词和投掷；桌面键盘回归测试不受影响；连续滑动不会卡住方向状态。

## P0-05 入口、继续游戏和地图选择

**Depends:** P0-01、P0-02、P0-03

**Files:**

- Modify: `index.html`
- Modify: `app.js`
- Modify: `styles.css`
- Create: `vendor/js/world-entry.js`
- Create: `tests/test-world-entry-contract.mjs`

**Steps:**

1. 在大厅首屏增加“继续上次”和三张主题农场卡片。
2. 从 `localStorage` 或 IndexedDB 读取最后地图、成熟作物数量和待复习词数量。
3. 点击地图卡直接进入对应世界，不再先进入无上下文的游戏目录。
4. 无历史记录时默认推荐森林农场。
5. 所有地图保持可进入，推荐不等于锁定。

**Acceptance:** 首次进入显示森林推荐；已有状态显示继续入口；三张地图均能正确解析 URL 和 bridge 信息。

## P0-06 首次加载和词库按需加载

**Depends:** P0-05

**Files:**

- Modify: `games/word-memory-map/index.html`
- Modify: `games/word-memory-map/game-data.js`
- Modify: `games/word-memory-map/game.js`
- Create: `tests/test-loading-contract.mjs`

**Steps:**

1. 去掉无 `vocab` 时强制替换为 `vocab=all` 的默认行为。
2. 默认加载 starter/core，用户选择 extension/all 时才加载对应包。
3. 预览图只加载当前地图和下一张候选地图。
4. 将开发用 `no-store` 与生产缓存策略分开。
5. 记录首屏资源清单，确保不把完整词库和所有主题背景提前加载。

**Acceptance:** 默认启动不请求 all 词库；选择 all 后仍能完整进入；资源失败时显示可理解的重试提示。

## P0-07 存档恢复与异常处理

**Depends:** P0-02、P0-03、P0-04

**Files:**

- Create: `vendor/js/session-resume.js`
- Modify: `games/word-memory-map/game.js`
- Modify: `games/word-memory-map/game-storage.js`
- Create: `tests/test-session-resume.mjs`

**Steps:**

1. 在 `pagehide/visibilitychange` 保存当前局快照。
2. 在启动时判断快照是否过期、版本是否兼容。
3. 提供“继续本局”和“重新开始”两个明确选项。
4. 保存失败时保留内存游戏，并显示非阻塞提示。
5. 对 JSON 损坏、存储空间不足和无权限场景写测试。

**Acceptance:** 刷新、切后台、返回和重新打开都能恢复；损坏数据不会阻塞游戏启动。
