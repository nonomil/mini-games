# 01 任务分布与角色

## 角色定义

| 角色 | 主要负责 | 不负责 |
| --- | --- | --- |
| 产品/系统 | 世界规则、任务、资源经济、优先级 | 直接修改素材路径 |
| 学习设计 | 词卡字段、题型、复习间隔、错误反馈 | 决定 CSS 布局 |
| 运行时工程 | JS 状态、存档、输入、加载、桥接 | 批量生成未经审核的词卡 |
| 内容/美术 | 地图主题、作物、NPC、图片、音频 | 修改核心学习算法 |
| QA/验证 | 契约测试、浏览器测试、验收记录 | 临时放宽验收标准 |

## 任务分布

| 工作流 | 任务 | 首要文件 | 可并行条件 |
| --- | --- | --- | --- |
| 世界底座 | P0-01、P0-02、P0-05 | `data/worlds/`、`vendor/js/world-state.js` | P0-01 完成后可拆分 |
| 学习底座 | P0-03、L-01 至 L-04 | `vendor/js/learning-memory.js`、`data/learning/` | 不依赖美术 |
| 输入与移动 | P0-04、X-02 | `vendor/js/world-input.js`、游戏 CSS | 可与学习底座并行 |
| 森林切片 | P1-01 至 P1-06 | `games/word-memory-map/`、`data/crops/forest.json` | 依赖 P0 |
| 太空扩展 | P2-01 至 P2-05 | `data/worlds/space-farm.json`、活动入口 | 依赖 P1 Gate |
| 外星扩展 | P3-01 至 P3-05 | `data/worlds/alien-farm.json` | 依赖 P2 共用规则 |
| 性能质量 | X-01、X-03 至 X-06 | `scripts/`、`tests/`、PWA 文件 | X-01 可提前开始 |

## 推荐执行批次

### 批次 A：底座

`P0-01 -> P0-02/P0-03/P0-04 -> P0-05 -> P0-06`

### 批次 B：森林垂直切片

`P1-01 -> P1-02 -> P1-03/P1-04 -> P1-05 -> P1-06 -> P1-07`

### 批次 C：移动端和性能

`X-01 -> X-02 -> X-03 -> X-04 -> X-05`

### 批次 D：地图扩展

`P2-01/P2-02 -> P2-03/P2-04 -> P2-05 -> P3-01/P3-02 -> P3-03/P3-04`

