# 04 P2 太空农场

P2 的目标是证明第二张地图不是简单换背景，而是使用不同资源、角色和学习强度。

## P2-01 太空世界配置

**Depends:** P1 Gate

**Files:**

- Create: `data/worlds/space-farm.json`
- Create: `data/worlds/space-scenes.json`
- Create: `data/worlds/space-npcs.json`
- Modify: `data/worlds/manifest.json`
- Create: `tests/test-space-world-contract.mjs`

**Acceptance:** 太空农场声明温室、能源、维修机器人、星港训练站和核心英语/科技词包；不复制森林农场逻辑文件。

## P2-02 温室和能源成长

**Depends:** P0-02、P2-01

**Files:**

- Create: `data/crops/space.json`
- Modify: `vendor/js/world-state.js`
- Modify: `games/word-memory-map/game.js`
- Create: `tests/test-space-energy.mjs`

**Steps:**

1. 将森林水滴映射为太空能源，但保留相同资源接口。
2. 配置氧气菜、星光豆和月尘花三类作物。
3. 正确完成英语或科技词任务时增加能源效率。
4. 增加温室机器的阶段变化，不增加复杂资源分支。

**Acceptance:** 太空作物能离线成长；能源只影响加速和装饰，不让玩家因资源不足无法学习。

## P2-03 星港训练站接入

**Depends:** P1-04、P2-01

**Files:**

- Modify: `games/typing-defense/web/` 下对应入口和桥接文件
- Modify: `games/learning-arcade/game.js`
- Create: `vendor/js/activity-bridge.js`
- Create: `tests/test-activity-bridge.mjs`

**Steps:**

1. 定义活动开始、完成、错词和奖励四类事件。
2. 将打字防守的独立完成结果回传到太空农场能源系统。
3. 保留活动自己的进度，不把它改成农场 DOM 子组件。
4. 处理重复完成事件，保证一次活动最多发一次农场奖励。

**Acceptance:** 从太空农场进入活动、完成、返回后能源增加；直接打开原游戏仍能独立运行。

## P2-04 核心科技词包

**Depends:** L-01 至 L-04

**Files:**

- Create: `data/learning/core-space.json`
- Modify: `data/vocab/` 对应 manifest
- Create: `tests/test-space-vocab.mjs`

**Acceptance:** 每张词卡有主题、发音、图片、难度和至少一种主动回忆题型；重复 ID、空音频和错误路径都被测试拦截。

## P2-05 轨道昼夜和空间反馈

**Depends:** P2-02

**Files:**

- Modify: `games/word-memory-map/styles.css`
- Modify: `games/word-memory-map/game.js`
- Create: `data/worlds/time-themes.json`

**Acceptance:** 轨道昼夜只影响色调、背景动画和 NPC 行为，不改变复习时间、不遮挡词语、不降低低端手机可读性。

## P2-06 P2 Gate

**Acceptance:** 玩家能够说出森林和太空的资源、NPC、作物、活动和学习强度差异；跨地图切换、刷新、奖励去重和 `npm test` 全部通过。
