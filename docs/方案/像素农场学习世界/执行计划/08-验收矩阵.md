## 手工验收脚本

### 移动端

1. 打开大厅，点击森林农场。
2. 不使用键盘移动角色到一块空地。
3. 播种，打开目标词卡，播放发音。
4. 完成一次独立回忆，确认获得资源。
5. 切后台或刷新，再回来查看作物和复习状态。
6. 进入太空农场，返回森林，确认世界状态没有重置。

### 桌面端

1. 使用 WASD 和方向键移动。
2. 使用鼠标选择目标和投掷。
3. 使用键盘完成打字活动。
4. 关闭声音，再刷新，确认设置保留。
