# 05 小游戏与建筑设计

## 1. 建筑与当前游戏的对应

| 建筑 | 当前项目入口 | 主要学习能力 | 在农场中的作用 |
| --- | --- | --- | --- |
| 单词探险屋 | `games/word-memory-map/` | 识别、回忆、听音、地图探索 | 主线玩法，产出种子和词汇印记 |
| 星港训练站 | `games/typing-defense/` | 键盘输入和拼写 | 太空农场的能源任务 |
| 拼音赛车场 | `games/learning-arcade/` | 拼音识别和反应 | 森林与天空农场的短局活动 |
| 汉字水泡池 | `games/hanzi-bubble-runner/`、`games/hanzi/` | 听音、认字、选择 | 森林农场的轻量活动 |
| 数学竞技场 | `games/math-pk/` | 口算和乘法 | 农场升级时的资源挑战 |
| 宠物图鉴馆 | `games/card-collection/` | 观察、收集、阅读 | 跨地图长期收藏 |
| 卡牌训练营 | `games/card-arena/` | 组合、策略、阅读 | 高阶奖励和伙伴训练 |

## 2. 主线和支线的区别

- 主线：单词探险屋 + 农场种植，负责让用户理解项目是什么。
- 支线：其他小游戏，每次 1-5 分钟，完成后回到对应农场领取奖励。
- 收藏：宠物、装饰、地图图鉴，提供长期目标但不阻塞学习。

## 3. 每个小游戏都要有三个出口

每个小游戏完成后至少提供：

1. 回到当前农场。
2. 再玩一局同难度。
3. 复习本局错词。

不要把用户重新送回一个没有上下文的游戏大厅。

## 4. 建筑升级

建筑升级不增加复杂菜单，而是带来可见变化：

- 学习屋升级：一次可保存的词卡更多，提示更清晰。
- 探险屋升级：解锁新的地图物件和敌人表现。
- 温室升级：可同时种植更多长线作物。
- 训练站升级：出现新的题型，但不强制提高速度。
- 宠物屋升级：伙伴在地图上出现新的待机动作。
