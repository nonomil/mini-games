# 06 任务、奖励与长期成长

## 1. 三层任务

### 引导任务

前 5 分钟完成：播种、听 3 个词、完成一次匹配、收获第一株作物。

### 地图任务

每张地图 8-12 个任务，围绕该地图主题：

- 森林：认识 10 个动物词，收集 3 种种子，帮助向导找到溪流。
- 太空：修复 3 台设备，完成 5 次输入，恢复温室能源。
- 外星：复习 10 个错词，稳定 3 颗变异晶体，找到传送门。

### 长期任务

跨地图记录：收获总数、稳定词数、伙伴数量、地图发现数和装饰收集数。

### RPG 探索任务

参考 RPG 学习系统后，任务可以表现为“每日探索路线”和“区域试炼”，但仍使用同一套学习事件：

- 每日探索路线：由今日到期词、最近错词和少量新词生成，控制在 3-8 分钟。
- 区域试炼：章节或地图里程碑的综合检查，未达标时给出补强路线，不清空长期进度。
- 语法之塔：仅在存在独立语法/表达内容包后开放，不用普通单词题冒充语法学习。
- Boss 生命值和地图完成度只做表现，不直接修改掌握度和复习间隔。

完整规则见 [RPG 探索地图与闯关方案](./11-RPG探索地图与闯关方案.md)。

## 2. 奖励结构

每次完成要同时给出三种反馈：

- 立即反馈：声音、动画、目标数变化。
- 短期奖励：种子、能源、星星、道具。
- 长期进展：熟练词数、地图图鉴、建筑等级或伙伴成长。

## 3. 奖励要服务学习

- 独立答对比看提示多获得少量额外奖励。
- 复习旧词可以获得稀有资源，避免玩家只追逐新词。
- 错词不扣掉已经拥有的物品。
- 长线作物不应成为强迫回访，所有成熟状态都可以等待。
- 每天最多提供一个轻量推荐任务，不做失败惩罚。

## 4. 宠物成长

宠物不只是图鉴数量。每只伙伴可以绑定一种学习支持：

- 森林向导：增加图片提示次数。
- 维修机器人：减少输入错误造成的时间损失。
- 翻译虫：把错词变成一轮低难度复习。
- 海龟邮差：提醒玩家有哪些作物成熟和词卡到期。

宠物能力最好是辅助，不要让玩家为了效率必须抽取或购买特定宠物。
