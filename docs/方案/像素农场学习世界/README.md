# 像素农场学习世界方案

这是一套面向当前“小游戏项目”的产品、内容、学习机制、农场成长和技术改造方案。

## 一句话定位

一个可以自由探索多个主题农场的像素学习世界：玩家通过认识、回忆和使用单词获得种子、道具和伙伴，让森林农场、太空农场和外星农场持续成长。

## 方案原则

1. 农场是主世界，学习行为是推动世界变化的主要行动。
2. 森林、太空、外星不是三个独立游戏，而是共享规则的主题农场。
3. 词库保持完整开放，地图和词包可以自由选择；任务只提供推荐，不制造硬锁。
4. 游戏奖励学习过程，但不把学习变成重复点击题目。
5. 作物不会因为离线或忘记浇水而死亡，成长是轻压力的长期回访理由。
6. 首次进入要快，手机要能单手操作，单局要能在 3-8 分钟内完成。

## 当前项目对应关系

当前项目已经具备 11 个游戏入口、12 个经典场景、80 个故事节点、完整词库、单词俯视地图、任务条、关卡、奖励和本地进度。优先级不是继续堆内容，而是把这些已有内容收束到一套可理解的世界规则里。

核心落点建议放在：

- 主世界和地图选择：`data/maps-manifest.json`、`games/explore-map/`
- 单词主玩法：`games/word-memory-map/`
- 小游戏训练站：`games/learning-arcade/`、`games/typing-defense/`
- 故事事件：`vendor/js/pixel-story-engine.js`、`vendor/js/exploration-detail.js`
- 宠物和卡牌成长：`vendor/js/card-collection.js`、`vendor/js/card-arena-ui.js`
