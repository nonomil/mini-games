# 00 总纲与产品定位

## 1. 产品定位

项目不再被用户理解为“很多小游戏的目录”，而应被理解为：

> 一个有多个主题农场的像素学习世界，小游戏是农场里的建筑和活动。

玩家拥有一个跨地图的角色、宠物、背包和学习档案。每张地图有自己的环境、作物、角色和故事，但使用同一套核心操作：探索、学习、种植、照料、收获、装饰、升级。

## 2. 目标用户

第一阶段建议聚焦 5-10 岁儿童与陪玩家长：

- 儿童需要立即看到“我做了什么”和“世界有什么变化”。
- 家长需要知道孩子复习了哪些词、哪些词还不稳定，而不是只看到一个总分。
- 低龄用户不适合复杂惩罚、强制签到、长时间倒计时和失败后清空进度。

## 3. 四个价值支柱

| 支柱 | 玩家感受 | 学习价值 | 当前项目基础 |
| --- | --- | --- | --- |
| 探索 | 每张农场都有新地点和角色 | 词汇按主题进入语境 | 经典场景、故事地图、主题背景 |
| 行动 | 移动、拾取、投掷、建造 | 学习结果改变行动结果 | 单词俯视地图、打字、拼音赛车 |
| 成长 | 作物成熟、建筑升级、宠物变化 | 复习带来长期收益 | 奖励、卡牌、宠物、积分 |
| 回访 | 离开后回来有收获和新任务 | 间隔复习自然发生 | 本地进度和复习词记录 |

## 4. 产品结构

```text
世界入口
  ├─ 森林农场：自然、动物、植物，适合第一次进入
  ├─ 太空农场：科技、交通、动作，适合英语主动回忆
  ├─ 外星农场：Minecraft、拓展词和错词复习
  └─ 后续主题：海洋农场、天空农场、糖果农场

每张农场
  ├─ 田地：种植和成长
  ├─ 学习屋：预习、听音、词卡
  ├─ 探险区：单词主玩法
  ├─ 训练站：短局小游戏
  ├─ 商店：种子、装饰、道具
  ├─ 伙伴区：宠物和 NPC
  └─ 传送门：前往其他主题农场
```

## 5. 不做的事情

- 不把所有地图改成完全不同的规则。
- 不让“答题数量”成为唯一成长指标。
- 不为了留存加入强制每日签到、作物死亡或错过惩罚。
- 不要求一次性加载全部 6000 余张词卡和所有地图素材。
- 不在第一阶段迁移到新游戏引擎；先复用当前 Vanilla JS 运行时。
