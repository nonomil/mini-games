# 03 单词学习机制

## 1. 学习目标

游戏的目标不是让玩家“见过很多词”，而是让词从认识逐渐变成能回忆、能识别、能使用。

每张词卡记录四类证据：

- 识别：看到英文能否选对图片或中文。
- 听辨：听到发音能否选择正确词义。
- 回忆：看到中文或图片能否找出英文。
- 使用：能否在游戏动作、拼写或简单句中使用。

## 2. 四次接触模型

### 第一次：发现

通过种子、NPC、地图物件或故事事件看到单词，配图和发音。第一次不计为完全掌握。

### 第二次：引导回忆

给出 2-3 个选项，让玩家把中文、图片和英文对应起来。错误时立即给出解释和发音。

### 第三次：主动回忆

在单词探险、打字防守或炮台玩法中，玩家要根据中文或发音主动选择英文目标。

### 第四次：延迟回忆

下一次进入农场或收获作物时，重新抽取上次词卡。这个阶段决定词是否进入稳定记忆。

## 3. 奖励与学习质量

奖励按回答质量区分：

| 状态 | 条件 | 奖励 |
| --- | --- | --- |
| 看过 | 只打开词卡 | 少量探索经验 |
| 提示后答对 | 使用图片、中文或首字母提示 | 基础奖励，并进入较短复习间隔 |
| 独立答对 | 没有提示直接完成 | 完整奖励，推进熟练度 |
| 连续延迟答对 | 跨会话仍能答对 | 词汇印记和稀有掉落 |
| 答错 | 选择错误或拼写错误 | 不扣长期资源，加入错词队列 |

不要让孩子通过反复点击“看答案”获得与主动回忆相同的奖励。

## 4. 错词反馈

错误反馈必须短而具体：

1. 先告诉玩家哪里错了，不使用羞辱性语言。
2. 播放正确发音并展示图片。
3. 让玩家立即完成一次低难度重试。
4. 把词放入地图中的“需要照顾的幼苗”或外星农场的“待修复晶体”。
5. 下一次会话优先复习，但不强制打断当前探索。

## 5. 学习强度档位

- 轻松：图片 + 听音 + 选择，适合森林农场。
- 标准：中文找英文、词义匹配、短句选择，适合主线。
- 挑战：键盘输入、听音拼写、限时目标，适合太空农场。
- 复习：错词混合旧词，适合外星农场。

同一张词卡可以在不同地图以不同强度出现，不需要复制词卡数据。
