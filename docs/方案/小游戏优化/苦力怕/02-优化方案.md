# 苦力怕优化方案

## 1. 优化目标

苦力怕应当成为项目里的“英语拼写训练站”：孩子看英文、中文、图片或听音，在怪物靠近前完成输入。优化重点不是增加战斗复杂度，而是让每次输入都产生清楚的学习反馈，并让错误词能够进入后续复习。

## 2. 当前主要问题

### P0：入口问题

`FEATURED_CATALOG` 中存在苦力怕卡片，但没有 `path`；`localGameUrl()` 对它不会走学习机特殊分支，最终链接可能为空。应明确使用：

```js
path: 'games/typing-defense/web/index.html'
```

并增加一个入口契约测试。

### P0：错误没有进入复习闭环

当前 `recentTaskIds` 只用于当前 session 的去重，开始新局时会被清空。它不是学习记录，不能回答“孩子昨天错过了哪些词”。输入错误多数情况下只触发抖动音效；怪物到达终点后扣心并换题，错误目标没有立即重试。

### P0：自动分级依据关卡，不依据掌握度

自动词库按第几关切换：第 1-2 关幼儿园，第 3-4 关小学低年级，第 5 关小学高年级，第 6 关初中。这样做容易让孩子在没有掌握当前词汇时被动进入更高年级。

### P1：默认训练仍偏向抄写

“看英文打英文”适合热身和键盘训练，但不能独立证明孩子记住了词义。需要把主动回忆作为单独模式，而不是只在结果页提醒“先听一听”。

### P1：失败压力与学习目标混在一起

生命值、倒计时和怪物接近很有游戏感，但低年级孩子答错时不应该马上被连续扣心。学习失败应转化为“慢一点、给提示、再试一次”，而不是直接结束。

## 3. 目标体验

### 第一次进入

1. 默认选择“幼儿园词库 + 看图/听音打词”。
2. 开始前展示 6 个目标和一个示例，不展示完整答案列表。
3. 第一题只出现一个怪物，速度慢，首字母键盘高亮。
4. 输入正确字母时，苦力怕后退、箭头命中、字母变绿。
5. 输入错误时，输入框轻微提示“这一位不对”，不立即扣心。

### 单个词的学习循环

```text
提示出现
 -> 孩子输入
 -> 正确：局部命中并记录独立答对
 -> 错误：标出错误位置，播放正确发音
 -> 同词重试：显示首字母或中文提示
 -> 完成：记录为提示后答对或独立答对
```

### 一局结束

结果页显示：

- `6/6` 完成数
- 首答正确率
- 提示次数
- 需要复习的词
- “复习本局错词”按钮
- “再玩一局”和“返回大厅”按钮

## 4. 模式设计

### 模式 A：看英文打英文

用途：键盘热身和熟悉拼写。

- 显示英文单词和中文释义。
- 不把它算作完整的主动回忆证据。
- 允许较快速度和多敌人。
- 适合第一次接触词库。

### 模式 B：看中文打英文

用途：主动回忆。

- 主卡只显示中文和图片。
- 英文答案只在错误反馈或完成后出现。
- 首字母提示消耗一次提示，但不扣长期资源。
- 适合记录真正的掌握度。

### 模式 C：听音打英文

用途：听辨和拼写。

- 开局自动播放一次英文发音。
- 提供“再听一次”，但记录播放次数。
- 可以在错误后同时播放中文释义和英文答案。
- 语音加载失败时仍显示文本提示，不能阻塞游戏。

### 模式 D：错词复习

用途：把错误转化为下一轮目标。

- 只抽取本局错词、最近到期词和连续错误词。
- 默认 4-6 个目标。
- 先使用看图/首字母提示，再回到中文打英文。
- 连续两次独立答对后移出高优先级错词队列。

## 5. 难度曲线

难度应拆成四个独立维度：词汇年级、输入速度、敌人数量、提示强度。

| 阶段 | 敌人 | 速度 | 词汇 | 失败处理 |
| --- | --- | --- | --- | --- |
| 热身 | 1 | 20-25 秒 | 3-4 字母或已见词 | 不扣心，错误后重试 |
| 基础 | 1 | 16-20 秒 | 3-5 字母 | 扣一次保护盾，继续本局 |
| 标准 | 2 | 12-16 秒 | 4-7 字母 | 可切换目标，错误进入复习 |
| 挑战 | 3 | 10-14 秒 | 长词和错词混合 | 允许失败，但不清空学习记录 |

自动分级建议改为：

- 当前词包连续两局首答正确率达到 80% 以上，才进入下一级。
- 首答正确率低于 50% 时，下一局优先加入错词并降低速度。
- 使用提示后答对可以继续升级，但不能与独立答对获得相同的熟练度。

## 6. 反馈细节

### 正确

- 当前字母立即变绿。
- 苦力怕后退一点，而不是每次都播放完整爆炸。
- 连续 3 个字母正确显示短连击反馈。
- 完成单词时播放单词发音和短奖励音。

### 错误

- 输入框显示错误位置，不清空已经正确的前缀。
- 提示文本具体到“中间字母需要再听一次”，不要只显示“错误”。
- 第一次错误：放慢怪物。
- 第二次错误：显示首字母或图片。
- 第三次错误：展示完整答案，要求再输入一次。

### 跳过

“换一个”不能简单丢弃任务。跳过应记录为 `gave-up`，把词加入本局复习列表，并在结果页提醒下次优先练习。

## 7. 数据和代码建议

### 词卡字段

```js
{
  id: "kindergarten-cat",
  word: "cat",
  translation: "小猫",
  image: "...",
  audio: "...",
  level: "kindergarten",
  skillTags: ["short-word", "cvc"]
}
```

### 局内任务字段

```js
{
  cardId: "english:kindergarten:kindergarten-cat",
  source: "new", // new | due | mistake
  promptMode: "meaning-to-word",
  hintUsed: 0,
  wrongLetters: [],
  startedAt: 0,
  completedAt: 0
}
```

### 建议拆分的职责

- `typing-session.js`：生成 6-8 个任务和当前索引。
- `typing-learning.js`：记录错误、提示和复习时间。
- `typing-render.js`：渲染怪物、键盘和反馈。
- `typing-bridge.js`：只负责向主站发送完成和奖励事件。

当前大部分逻辑集中在 [`game.js`](../../../../games/typing-defense/web/game.js)，先抽学习记录和任务编排即可，不需要立即重写动画系统。
