# 苦力怕当前游戏介绍

## 1. 游戏定位

苦力怕是项目中的英语键盘输入小游戏。玩家需要在苦力怕靠近终点前，根据屏幕提示输入字母、拼写单词或完成其他类型的练习。当前玩法的核心反馈是“输入一个正确字母，敌人后退或受到攻击”，适合用于低门槛的英语字母和单词拼写练习。

## 2. 当前入口和代码

- 游戏入口：[`games/typing-defense/web/index.html`](../../../../games/typing-defense/web/index.html)
- 主要运行逻辑：[`games/typing-defense/web/game.js`](../../../../games/typing-defense/web/game.js)
- 相关资源和页面：`games/typing-defense/web/`

大厅中的苦力怕卡片目前没有正确配置实际路径，后续需要由大厅进入这个入口。

## 3. 当前玩法流程

```text
进入游戏
 -> 选择或读取当前词库与训练模式
 -> 生成一组短局目标
 -> 苦力怕从远处靠近
 -> 玩家逐字输入答案
 -> 输入正确时产生攻击和奖励反馈
 -> 苦力怕到达终点时扣除生命并切换目标
 -> 完成本局或生命耗尽
 -> 显示本局结果
```

当前默认体验以短局为主，一局约有 6 个目标。每个目标通常与一个单词、字母、拼音或数学任务相关。

## 4. 当前已有能力

- 默认 6 个目标的短局结构。
- 根据年级词库自动分级。
- 单字拼音、词语拼音、字母、数学等多种训练模式。
- 逐字输入时高亮键盘和局部命中反馈。
- 语音播放和“听一听”按钮。
- 星星、连击和金币等即时奖励。
- 1-3 个苦力怕的波次变化。
- 白天、黄昏、林地等场景变化。
- 错误后通过生命值、敌人推进和下一目标切换制造紧迫感。

## 5. 当前适合保留的部分

1. 苦力怕靠近和输入攻击之间的因果关系直观，孩子不需要先理解复杂规则。
2. 逐字高亮和局部反馈能让孩子知道自己卡在哪一个字母。
3. 短局结构适合反复练习，也方便后续加入错题复习。
4. 语音、键盘高亮和场景变化已经提供了足够的表现力，后续重点应放在学习记录和题目编排。

## 6. 当前限制

- 大厅入口与实际页面路径尚未完全接通。
- 当前错误目标主要停留在本局状态，不能稳定地跨局复习。
- 自动分级主要依据关卡序号，不能准确反映词卡掌握度。
- “看英文打英文”容易变成照着抄写，主动回忆证据不足。
- 生命、倒计时和敌人推进可能放大低龄孩子的失败压力。
