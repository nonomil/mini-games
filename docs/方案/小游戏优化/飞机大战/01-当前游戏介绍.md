# 飞机大战当前游戏介绍

## 1. 游戏定位

飞机大战是项目中偏挑战型的英语主动输入小游戏。玩家操纵战机，在敌机、子弹和障碍物之间完成英文单词输入；输入正确的字母会发射攻击，拼完整个单词后击破对应敌机。

它比苦力怕拥有更多战斗和成长元素，适合作为孩子熟悉基础词卡之后的进阶玩法。当前系统的主要风险是战斗操作较多，容易让躲避、装备和连击盖过单词学习本身。

## 2. 当前入口和代码

- 游戏入口：[`games/learning-arcade/?game=word-shooter`](../../../../games/learning-arcade/index.html)
- 主要运行逻辑：[`games/learning-arcade/game.js`](../../../../games/learning-arcade/game.js)
- 共用运行页面：`games/learning-arcade/index.html`

## 3. 当前玩法流程

```text
进入飞机大战
 -> 生成多个带有单词目标的敌机
 -> 玩家移动战机并选择目标
 -> 输入英文单词
 -> 每个正确字母触发攻击
 -> 完成单词后击破敌机
 -> 处理敌方子弹、障碍和掉落
 -> 进入更高波次或 Boss 阶段
 -> 结算战斗奖励和局内学习数据
```

当前玩法将“目标选择、英文输入和战斗反馈”放在同一条操作链中。难度越高，同时出现的敌机、障碍和战斗机制越多。

## 4. 当前已有能力

- 多个敌机同时出现，并按单词首字母进行目标锁定。
- 输入正确字母时发射子弹，完成单词后击破敌机。
- 基础、进阶、完整三个难度档位。
- 战机、武器、装备升级和星尘成长。
- 护盾、敌方子弹、雷区和陨石等战斗要素。
- Boss 阶段和阶段性战斗目标。
- 局内记录首答正确、重试、正确字母、错误字母和目标切换等指标。
- 语音朗读当前目标。

## 5. 当前操作方式

桌面端目前同时存在移动和输入需求：

- 方向键或 `W/A/S/D`：移动战机。
- 字母键：输入单词。
- `Backspace`：处理当前输入。
- `Enter`：确认或进入下一步。
- `Space`：暂停。

其中 `W/A/S/D` 也可能是单词中的字母，移动逻辑与输入逻辑存在冲突，是当前最需要优先处理的交互问题之一。

## 6. 当前适合保留的部分

1. “正确字母发射子弹”的反馈比单纯答题更有动作感。
2. 多目标和 Boss 为后续复习关卡提供了扩展空间。
3. 装备成长能够提供长期游玩动力，但不应替代词卡掌握度。
4. 局内学习指标已经比单纯记录分数更丰富，可以继续接入跨局学习记录。

## 7. 当前限制

- `W/A/S/D` 与英文输入发生按键语义冲突。
- 敌机上的完整英文和中文提示可能让孩子直接复制答案。
- 敌机撞击或护盾耗尽时，失败压力可能直接中断学习过程。
- 战斗元素在高难度中集中出现，容易遮挡或稀释拼写目标。
- 长期保存偏重装备和战斗成长，词卡掌握度还没有成为核心进度。
