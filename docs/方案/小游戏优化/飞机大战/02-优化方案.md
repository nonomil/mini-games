# 飞机大战优化方案

## 1. 优化目标

飞机大战应当成为“英语主动输入 + 多目标决策”的挑战玩法。它可以比苦力怕更刺激，但刺激应建立在孩子已经理解词卡的基础上。优化时需要先保护拼写目标，再逐步开放移动、躲避、装备和 Boss 等挑战层。

## 2. 当前主要问题

### P0：W/A/S/D 与单词输入冲突

当前 `W/A/S/D` 既可以移动战机，又可能是单词中的字母。代码会根据当前目标判断按键用途，造成以下问题：

- 孩子不知道按键会让战机移动还是输入字母。
- 输入错误可能被当作移动，错误统计不准确。
- 单词包含 `a`、`s`、`d`、`w` 时，移动和输入的优先级会改变。
- 移动注意力会打断拼写节奏。

默认方案应改为：方向键负责移动，字母键只负责输入；WASD 作为设置里的可选控制方案，而不是默认行为。

### P0：目标词展示得太完整

如果敌机上始终显示完整英文和中文，孩子主要是在复制文本。这个模式可以保留为热身，但必须增加“中文/图片/听音到英文”的主动回忆模式。

### P0：失败结束太重

敌机撞击会直接结束当前回合。对于学习游戏，失败应该保留已完成词汇和错误记录，并把当前词加入复习队列。护盾应承担“容错”的作用，而不是只作为额外的视觉数字。

### P1：战斗系统会压过学习目标

敌机数量、移动、子弹、Boss、掉落和装备升级同时出现时，孩子可能只关注躲避和连击。应让不同玩法在不同难度阶段逐步开放。

### P1：长期保存的是装备，不是词卡掌握度

当前 localStorage 主要保存设置和机库成长，局内 learning 数据会在开始新局时重建。这样能保存“战机变强”，却不能保存“哪些词变熟”。

## 3. 目标体验

### 基础模式

1. 只出现一到两架敌机。
2. 战机自动保持安全位置，不要求移动。
3. 目标卡只显示中文、图片或发音按钮。
4. 输入英文完成后击破敌机。
5. 第一次错误只降低敌机速度，不扣长期奖励。

### 进阶模式

1. 同时出现两架敌机。
2. 目标卡显示首字母和中文，其他敌机只显示部分信息。
3. 孩子需要先选择目标，再完成输入。
4. 移动只作为轻量辅助，不与新单词同时首次出现。

### 完整模式

1. 三到四架敌机和有限护盾。
2. 增加敌方子弹、特殊地形和 Boss。
3. 目标词可来自新词、到期词和错词混合队列。
4. 只有完成一小段复习后才进入 Boss，而不是一开始就引入所有机制。

## 4. 操作方案

### 桌面端

默认控制：

- 方向键：移动。
- 字母键：输入单词。
- `Backspace`：删除当前字母。
- `Enter`：确认或开始下一步。
- `Space`：暂停。

不要默认把字母键分配给移动。若保留 WASD，需要在开局设置中明确显示“WASD 仅用于移动，输入时请使用独立字母键”，并保证目标输入优先级稳定。

### 移动端

- 左下角使用固定方向盘或四向按钮。
- 右侧保留听音、提示和暂停按钮。
- 字母输入使用屏幕键盘，不能要求手机用户召唤系统键盘后再输入。
- 控制按钮最小触控区域 44px。
- 使用 Pointer Events，避免快速点击或滑动时丢失输入。

## 5. 学习模式设计

### 模式 A：看英文打英文

用于熟悉键盘和单词外形。显示完整英文，但奖励只算基础奖励。

### 模式 B：看中文打英文

用于主动回忆。敌机显示中文或图片，英文只有在输入错误、使用提示或击破后出现。

### 模式 C：听音打英文

用于听辨。开局播放英文发音，屏幕只显示图片或中文。听音按钮可以重复播放，但必须记录播放次数。

### 模式 D：目标选择 + 拼写

先从两架敌机中选择与中文对应的目标，再输入完整英文。这个模式把识别和回忆分成两步，更适合进阶学习。

## 6. 多目标机制

### 基础阶段

只允许一个锁定目标，其他敌机作为背景。孩子先学会“输入一个词会发生什么”。

### 过渡阶段

出现两个目标，但只允许按首字母切换。目标词首字母应尽量不同，避免孩子因歧义受挫。

### 挑战阶段

允许相同首字母的目标同时出现，但必须给出明显的目标选择状态，并提供“锁定/取消锁定”操作。不能依赖孩子猜当前输入会锁定哪一个敌机。

### 不建议的做法

- 一开始同时出现四架敌机。
- 让孩子在输入新词的同时躲避密集子弹。
- 让装备数值直接替代正确输入。
- 用更快速度掩盖词汇难度没有分层的问题。

## 7. 武器和奖励设计

武器应体现操作体验差异，不应改变学习答案的公平性。

| 武器 | 作用 | 学习含义 |
| --- | --- | --- |
| 基础激光 | 稳定单发 | 标准练习 |
| 三重光束 | 连续正确时扩大反馈 | 奖励连续独立答对 |
| 追踪导弹 | 允许一次目标修正 | 低压力辅助，不替代输入 |
| 穿透激光 | 完成错词复习后获得 | 奖励复习行为 |

星尘可以继续保留，但奖励分成两部分：

- 完成游戏奖励：完成目标即可获得。
- 学习质量奖励：独立答对、少用提示、延迟复习答对时额外获得。

失败不能扣除已有星尘、装备或长期资源。

## 8. 回合和 Boss 设计

### 推荐回合结构

```text
预热 2 词
 -> 标准输入 2-3 词
 -> 错词复习 2 词
 -> 小奖励结算
 -> 可选 Boss 或下一阶段
```

基础模式 6-8 词即可完成；进阶和完整模式应拆成多个阶段，不要把 16 或 24 个词做成一次不可中断的长局。

### Boss 的学习作用

Boss 不应只是血量更多。建议设计成复习检查：

- Boss 的每一格生命对应一个本局错词。
- 输入错词的正确拼写才能造成伤害。
- 首次错误时 Boss 暂停攻击并播放发音。
- 完成全部错词后才能进入最终奖励。

这样 Boss 才能推动复习，而不是单纯延长战斗。

## 9. 数据和代码建议

### 敌机学习字段

```js
{
  cardId: "english:grade1:word-cat",
  promptMode: "meaning-to-word",
  mistakes: 0,
  correctLetters: 0,
  wrongLetters: 0,
  hintUses: 0,
  targetSwitches: 0,
  firstTry: true,
  startedAt: 0
}
```

### 建议拆分的职责

- `word-shooter-state.js`：敌机、战机和回合状态。
- `word-shooter-input.js`：键盘、屏幕键盘和目标锁定。
- `word-shooter-combat.js`：子弹、护盾、碰撞和 Boss。
- `word-shooter-learning.js`：词卡任务、错误记录和复习队列。
- `word-shooter-render.js`：舞台和 HUD。

当前所有职责集中在 [`game.js`](../../../../games/learning-arcade/game.js)，可以先把输入映射和学习记录抽出，之后再拆战斗动画。

## 10. 验收清单

- [ ] 默认字母键不会被移动逻辑拦截。
- [ ] 方向键移动和字母输入可以同时正确工作。
- [ ] 基础模式只出现一个学习目标。
- [ ] 中文打英文模式不显示完整英文答案。
- [ ] 敌机撞击后不会清除已完成词和错词记录。
- [ ] 护盾耗尽后仍可进入结果页复习错词。
- [ ] Boss 至少有一个复习相关机制。
- [ ] 星尘和学习掌握度分别保存。
- [ ] 结果页显示首答正确率、提示次数和错词。
- [ ] 测试覆盖单词含 `a`、`s`、`d`、`w` 的输入场景。
- [ ] 移动端覆盖屏幕方向键、屏幕键盘和暂停恢复。
