# 拼音赛车当前游戏介绍

## 1. 游戏定位

拼音赛车是项目中的汉字与拼音训练小游戏。玩家操纵小车在赛道上换道，接住与当前汉字、图片或声音匹配的拼音卡片。它已经具备较完整的赛道表现力，适合承载“认拼音、辨析拼音和输入拼音”三个层次的训练。

当前实际玩法主要是“看汉字选拼音”，因此更准确地说，它已经完成了拼音识别游戏的基础形态，但还没有完全成为拼音输入游戏。

## 2. 当前入口和代码

- 游戏入口：[`games/learning-arcade/?game=word-cannon`](../../../../games/learning-arcade/index.html)
- 主要运行逻辑：[`games/learning-arcade/game.js`](../../../../games/learning-arcade/game.js)
- 共用运行页面：`games/learning-arcade/index.html`

## 3. 当前玩法流程

```text
进入拼音赛车
 -> 生成汉字或词语目标
 -> 拼音卡片沿三车道出现
 -> 玩家移动小车接住目标卡片
 -> 接到正确卡片时获得反馈和奖励
 -> 接错时保留原任务并生成重试波次
 -> 经过地图设施和赛道阶段
 -> 完成本局并查看最近复习内容
```

当前通过赛道移动制造实时操作感，通过正确卡片和重试波次维持答题节奏。

## 4. 当前已有能力

- 看到汉字，接住正确拼音卡。
- 三车道以及上下左右移动。
- 基础、进阶、完整三档难度。
- 多张主题地图和赛道设施。
- 答错后保留原任务并生成重试波次。
- 语音播放汉字和拼音。
- 结果页显示首答正确、重试次数和最近几项复习内容。
- 已有弯道、分叉、隧道、声调桥和终点冲刺等表现元素。

这些弯道、分叉和设施目前主要通过固定背景图、CSS 透视、渐变和 DOM 覆盖层表现。它们看起来像赛道主题，但还不是一个可以持续推进、转弯、分支和生成新路段的赛道世界。

## 5. 当前操作方式

桌面端主要依靠方向键控制小车：

- 左右键：换道。
- 上下键：控制靠近或远离卡片。
- 可选 `A/D/W/S`：辅助移动。

移动端提供赛道底部控制按钮，并支持点击车道或滑动操作。当前题目、卡片和控制区需要继续做响应式布局检查，避免相互遮挡。

## 6. 当前适合保留的部分

1. “移动小车接住正确卡片”的隐喻清楚，适合儿童快速理解。
2. 答错后立即保留原任务并重试，是目前最值得继续保留的学习机制。
3. 地图和赛道设施已经提供了按学习主题组织内容的基础。
4. 汉字发音、拼音发音和重试波次可以扩展为完整的听辨与延迟复习闭环。

## 7. 当前限制

- 当前输入主要是移动选卡，不能证明孩子能够独立写出完整拼音。
- `normalizePinyin()` 去除声调后，标准化数据不适合直接承担声调训练。
- 结果页的复习内容主要是文字展示，不能直接点击进入复习。
- 基础干扰项差异较大，孩子可能通过排除法答题。
- 进阶和完整模式变成长局后，学习反馈会被赛道过程稀释。
- `WORD_CANNON_MAPS` 主要负责切换固定 WebP 背景，地图变化更像换皮，不会随着车辆前进真正发生空间变化。
- 当前运动主要是拼音卡片的 `y` 坐标下移和小车位置变化，赛道中心线、路宽、弯道和镜头没有独立的运动模型。
- 赛道背景使用 `background-size: cover` 铺满容器，无法稳定表达“远处进入、近处经过、转弯离开”的赛车空间关系。

详细改进内容见：[拼音赛车优化方案](./02-优化方案.md)。
