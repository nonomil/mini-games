# 网球学英语优化方案

## 1. 新增结论

建议把网球学英语作为一个独立的新小游戏推进，不要直接塞进拼音赛车或飞机大战的现有模式中。它的核心交互不是换道或逐字输入，而是“理解释义后选择表达，再用回球完成选择”。独立设计可以让球场、回合、目标卡和复习反馈围绕同一个学习动作展开。

第一版只验证一件事：孩子能否在有趣的对打节奏中，根据释义或例句选出正确的英文表达，并愿意在失误后复习它。

## 2. 学习目标和模式

### 2.1 主模式：释义找表达

屏幕顶部显示一条短释义，球场底线出现 3 张表达卡。玩家把球打向正确卡片：

- 正确卡片：赢下一球，播放表达发音并短暂展示例句。
- 错误卡片：球落网或被对手接回，暂停当前回合，展示正确表达和发音。
- 不确定时：允许播放音频或查看短提示，但提示后的正确不计为独立掌握。

### 2.2 进阶模式：语境辨析

顶部显示一个简单英文例句，三张卡使用同一词性或相近含义的表达。孩子需要根据语境判断，而不是只看中文释义。

例子：

```text
提示：I am very tired after the long trip.
选项：worn out / look forward to / take part in
目标：根据语境选出 worn out
```

### 2.3 听音模式：听表达找卡

隐藏文字释义，先播放目标表达或例句。玩家可以重播，但每次重播都记录在学习数据中。低龄或初学者可以同时显示图片、中文释义或词性提示。

### 2.4 复习模式：错词再打一局

只抽取本局错词、到期词和最近被提示的表达，顺序固定为：

```text
看释义选表达
 -> 听音选表达
 -> 例句辨析
 -> 可选：输入表达的关键部分
```

最后一步只作为巩固，不把网球游戏变成另一个打字游戏。

## 3. 推荐的回合结构

### 3.1 单分流程

```text
准备阶段：显示释义、例句或播放音频
 -> 选择阶段：确认 2-3 张目标卡的位置
 -> 回球阶段：控制球拍将球打向目标区域
 -> 判定阶段：命中正确/错误卡片
 -> 微复习：播放发音，展示释义和例句
 -> 下一分
```

准备阶段不设置倒计时。孩子正在读释义或听音时，球拍和球都保持暂停，避免阅读速度变成不必要的失败原因。

### 3.2 一局结构

参考“抢 7”比赛，但按学习负荷做分层：

| 模式 | 得分目标 | 题目数量 | 适用场景 |
| --- | --- | --- | --- |
| 练习 | 3 分 | 3-5 张卡 | 第一次接触词包 |
| 标准 | 7 分 | 7-10 张卡 | 日常复习 |
| 挑战 | 7 分 + 复习加赛 | 10-12 张卡 | 熟悉词包和相似表达 |

一张表达卡在同一局中最多自动重现一次。错题复现不是惩罚，而是局末或下一分中的学习机会。完整的一局不宜让孩子在 20 个以上表达之间持续切换。

### 3.3 两次失误的处理

参考原型可以保留“两次没击中后丢分”的比赛压力，但要改成两层状态：

1. 第一次失误：球落网，立即显示正确表达、发音和例句；本分进入复习标记。
2. 连续第二次失误：对手得分，当前表达进入本局复习加赛；不清除已有学习记录。
3. 同一表达复习时答对：可以追回基础奖励，但仍区分“提示后答对”和“独立答对”。

这样既保留网球的比分张力，也不会因为一次操作失误让孩子直接失去学习机会。

## 4. 击球操作设计

### 4.1 MVP 操作：三分区回球

第一版不要先做复杂物理。将对手场地分成左、中、右三个目标区，每张表达卡固定在一个区域：

- 桌面端：左右方向键或鼠标选择击球方向，`Space` 击球。
- 移动端：三个大击球按钮或左右拖动球拍。
- 球拍有较宽的有效区域，击球方向由球拍所在区域决定。
- 目标卡位置在准备阶段保持稳定，孩子可以先读卡再击球。

这个设计保证“学习判断”是主要动作，“手眼反应”只是表现层。

### 4.2 进阶操作：落点控制

熟悉后才加入球拍位置、击球时机和反弹角度。落点控制可以增加体育游戏感，但必须保留辅助线、慢速回放和自动吸附，避免孩子因为像素级碰撞错过正确卡片。

### 4.3 正反手与球场设置

正手、反手、握拍习惯和场地表面可以作为外观或轻微操作变化：

- 草地：球速略快，颜色明亮。
- 硬地：标准模式默认场地。
- 红土：球速较慢，适合复习模式。

这些设置不能改变词卡答案、正确率计算或复习队列。第一版优先保证规则一致，避免装饰选项变成额外学习负担。

## 5. 候选表达设计

### 5.1 内容包优先

每个词包应来自明确的书目、教材章节、绘本主题或人工整理的表达清单。单张卡不能只有一个英文词，还应尽量包含：

- 表达本身。
- 简单英文释义。
- 中文释义。
- 一个短例句。
- 发音和音频。
- 词性或表达类型。
- 内容来源和难度级别。
- 易混淆表达列表。

### 5.2 三卡干扰项规则

候选卡不能随机抽三个词。推荐按以下优先级生成：

1. 同一主题、同一词包，保证孩子有语境。
2. 词性相同，避免孩子只看词性排除。
3. 难度接近，不能出现一个极难表达和两个幼儿词。
4. 语义有一定相似度，但在当前例句中只有一个自然答案。
5. 不把两个都能成立的近义词放在同一道题里，除非题目明确要求辨析语境。

### 5.3 英文界面分层

参考项目使用全英文菜单和鼓励语，这个方向可以保留，但需要按词包难度开放：

| 界面层级 | 提示内容 | 适用用户 |
| --- | --- | --- |
| 中文辅助 | 中文释义、中文按钮、英文答案 | 初学者 |
| 双语 | 简单英文释义 + 中文悬浮提示 | 有基础用户 |
| 英文沉浸 | 英文释义、英文反馈、英文菜单 | 熟悉词包用户 |

鼓励语可以使用短英文，例如 `Nice shot!`、`Good read!`、`Try again!`，但错误反馈必须至少让孩子知道“错在哪里、正确表达是什么、下一步怎么再试”。

## 6. 难度和速度分离

网球的球速、回球窗口和对手强度都属于操作难度，不能直接等同于词汇难度。建议使用四个独立参数：

| 参数 | 低难度 | 高难度 |
| --- | --- | --- |
| 词汇 | 已学短词和熟悉表达 | 相似搭配和长表达 |
| 候选 | 3 个差异明显的卡片 | 3 个同词性、相近语义卡片 |
| 球速 | 慢速、可暂停 | 稳定加速、有明确回球窗口 |
| 提示 | 中文/图片/发音 | 英文释义和例句，可少量提示 |

推荐先提高候选项质量，再提高球速。孩子如果连续因为操作失败，下一分应自动放慢球速或扩大击球区域；如果连续因为词义混淆失败，才应该进入同主题的对比复习。

## 7. 结果页和复习闭环

结果页不只显示比分，应同时显示：

- 比分和场地。
- 首次选对数量。
- 使用提示后选对数量。
- 听音后选对数量。
- 错误表达及错误类型。
- 每个表达的下一次复习时间。
- “复习本局错词”“再打一局”“返回大厅”三个出口。

复习卡片要可以点击。每张卡先显示释义，让孩子再次选择表达；答错后再显示完整答案、发音和例句。不要把十个表达拼成一段静态文本。

### 8.3 建议的代码边界

如果后续实现，建议新建独立目录 `games/english-tennis/`，不要把球场状态硬塞入 `games/learning-arcade/game.js`：

- `tennis-content.js`：表达卡、释义、例句和干扰项。
- `tennis-session.js`：新词、到期词、错词和比赛回合编排。
- `tennis-input.js`：键盘、鼠标、触控和击球方向。
- `tennis-rally.js`：球、球拍、目标区和回球状态。
- `tennis-learning.js`：记录首答、提示、听音、错误类型和复习时间。
- `tennis-render.js`：球场、表达卡、比分和反馈。

共享学习记录继续由 `vendor/js/learning-progress.js` 负责，网球游戏只发送统一的卡片事件。

## 9. 分阶段实施

### P0：验证学习动作

- 创建独立入口和静态球场。
- 实现 3 个表达卡、三分区回球和暂停准备阶段。
- 使用一个人工精选的 20-30 张表达小词包。
- 实现英文释义、中文辅助、音频和错误后立即复习。
- 结果页区分首次选对、提示后选对和错误表达。
- 暂不加入复杂球体物理、装备、排行榜和多人联机。

### P1：提高内容和复玩价值

- 增加例句辨析和听音找表达模式。
- 接入共享到期复习队列。
- 增加草地、硬地、红土三个主题场地。
- 加入抢 7 比分、赛段小结和错题加赛。
- 根据错误类型生成同主题、同词性的干扰项。

### P2：长期玩法

- 赛季、排行榜和好友挑战，但排行榜同时展示学习质量，不能只按时长或比分排名。
- 主题化内容包和书目进度。
- 家长或老师查看表达掌握报告。
- 可选的落点控制、正反手和更丰富的球场动画。

## 10. 验收清单

- [ ] 大厅可以进入独立的网球学英语页面。
- [ ] 首次进入 30 秒内可以打出第一球。
- [ ] 题目准备阶段没有强制倒计时，孩子可以读完释义再开始。
- [ ] 每道题明确只有一个语境上成立的正确表达。
- [ ] 球速或碰撞失误不会被直接记录为词义错误。
- [ ] 答错后 2 秒内显示正确表达、发音和例句。
- [ ] 同一错误表达可以在本局或下一局再次出现。
- [ ] 结果页可以点击进入本局错词复习。
- [ ] 中文辅助、双语和英文沉浸三种界面层级可切换。
- [ ] 表达卡包含来源、释义、例句和音频字段。
- [ ] 基础模式不依赖复杂物理也能完成一局。
- [ ] 复习记录接入共享学习进度，不与比分或场地装饰混存。
