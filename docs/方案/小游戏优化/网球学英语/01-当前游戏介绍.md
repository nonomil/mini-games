# 网球学英语当前游戏介绍

## 1. 项目状态

网球学英语是根据两份参考项目整理出的新游戏方向，目前仓库中还没有对应的运行入口和游戏代码。本文件描述参考原型和建议的 MVP 边界，不把参考文章中的网页游戏当作本项目已经实现的功能。

## 2. 游戏定位

网球学英语不是完整的网球模拟器，而是一个带有网球视觉和对打节奏的“表达复习器”。玩家看到英文释义、简单英文解释、例句或听到音频后，在场地另一侧的 2-3 张表达卡中选择正确答案，并用回球动作命中它。

它主要训练：

- 从释义回忆英文单词或表达。
- 在相似表达之间进行语境辨析。
- 从听音或例句识别目标表达。
- 在错误之后再次回忆同一张词卡。

它不承担逐字拼写的主要责任，完整拼写继续由苦力怕和飞机大战负责。这样可以让四个小游戏形成互补，而不是都重复“看答案打字”。

## 3. 参考原型的核心玩法

参考项目采用类似 Pong 的简化网球对打：

```text
显示英文释义或学习提示
 -> 场地另一侧出现 3 个英文表达卡片
 -> 玩家控制回球方向
 -> 网球命中正确表达卡片
 -> 得分并继续下一球
 -> 失误后暂停，展示正确表达并学习
 -> 一局结束后集中复习本局表达
```

参考设计还包含精选书目词汇、草地/硬地/红土场地、抢 7 对打、正反手设置、英文界面和局后复习等元素。

## 4. 与现有小游戏的关系

| 游戏 | 主要动作 | 主要学习证据 | 适合内容 |
| --- | --- | --- | --- |
| 苦力怕 | 逐字输入 | 主动拼写 | 单词、字母、基础听写 |
| 飞机大战 | 目标选择 + 输入 | 多目标主动拼写 | 已熟悉单词、挑战词包 |
| 拼音赛车 | 换道选卡/拼音输入 | 拼音识别和辨析 | 汉字、拼音、声调 |
| 网球学英语 | 选择表达 + 回球 | 释义到表达的回忆 | 短语、搭配、例句 |

网球学英语最适合作为“表达复习和语境辨析”入口，尤其适合来自绘本、教材章节或社群读本的精选表达，而不是从完整词库中完全随机抽取单词。

## 5. 参考原型中值得保留的能力

1. 用英文释义或简单英文说明代替直接展示中文答案，能增加主动回忆。
2. 每次只给 2-3 个候选表达，规则容易理解，适合快速开始。
3. 网球动作、球场和音效能让学习判断拥有明确的结果反馈。
4. 抢 7 的比赛目标比单纯刷题更有局势感。
5. 草地、硬地、红土等场地可以提供主题变化，而不必改变学习规则。
6. 结束后的复习页面能把一次对打转化为真正的学习闭环。

## 6. 参考原型暴露的风险

- 赛车项目本身偏重反应速度，可能让孩子来不及阅读释义；网球项目也不能把球速作为主要难度来源。
- 三张卡片如果差异太大，孩子可以用排除法，不一定真正理解表达。
- 全英文菜单和反馈适合有基础的孩子，不应成为所有人的默认门槛。
- 一局复习 10 个以上表达可能造成短时信息过载，需要按阶段结算。
- 两次没击中就失分或停止时，必须先展示正确答案和发音，不能让失败直接吞掉学习记录。
- 参考项目的词汇质量依赖人工精选；如果本项目没有内容包质量标准，游戏动作再漂亮也会变成随机选择题。
