# 跨游戏基础能力

## 1. 为什么要抽共享能力

苦力怕位于 `games/typing-defense/web/game.js`，飞机大战和拼音赛车共享一个较大的 `games/learning-arcade/game.js`，网球学英语计划使用独立运行目录。目前各运行时各自维护局内的 `hits`、`misses`、`learning` 或 `completedReview`，导致：

- 一个游戏知道孩子错过了什么，另一个游戏不知道。
- 结果页只能显示本局统计，无法安排下一次复习。
- 同一张词卡在不同游戏里可能被当成不同任务。
- 修改学习规则时需要同时改三套逻辑。

共享模块应只负责“学习记录和任务编排”，不负责角色移动、碰撞或动画。

## 2. 词卡身份规范

### 英语词卡

```text
english:{packId}:{cardId}
```

如果词库没有稳定的 `cardId`，暂时使用标准化后的单词，但必须把词包 ID 纳入 key，避免不同词包中的同形词互相覆盖。

### 拼音词卡

```text
pinyin:{packId}:{汉字}:{原始拼音}
```

原始拼音用于显示和语音，标准化拼音只用于检索和比较。不能用去掉声调后的字符串作为唯一身份。

### 英语表达卡

```text
english-expression:{packId}:{cardId}
```

表达卡的 `cardId` 必须稳定，不能只用表达文本生成。一个表达在不同书目、不同例句或不同难度下可能承担不同学习任务，应由内容包明确区分。建议同时保存 `expression`、`definitionEn`、`definitionZh`、`example`、`audio`、`level` 和 `confusionSet`，显示值、释义、语音和复习身份不要混在一个字符串里。

## 3. 任务状态机

```text
new
  -> presented
  -> independent-correct
  -> due-review
  -> mastered

presented
  -> wrong
  -> guided-retry
  -> due-review
```

提示后的正确答案进入 `guided-correct`，不能与 `independent-correct` 等价。

## 4. 题目编排

每次进入游戏时生成一个不可变的 session：

```js
{
  id: "session-...",
  gameId: "word-shooter",
  domain: "english",
  packId: "kindergarten",
  cards: [
    { cardId: "...", source: "review", difficulty: "guided" },
    { cardId: "...", source: "new", difficulty: "basic" }
  ],
  currentIndex: 0,
  startedAt: 0
}
```

这样可以在刷新后恢复“当前练习到哪一题”，而不是只恢复词包和难度设置。

## 5. 错误标签

建议先使用有限的枚举，避免一开始引入复杂的自动诊断：

### 英语

- `wrong-first-letter`
- `wrong-middle-letter`
- `wrong-ending`
- `slow-completion`
- `gave-up`
- `wrong-definition`
- `wrong-context`
- `missed-target`
- `audio-replay`

### 拼音

- `wrong-initial`
- `wrong-final`
- `wrong-tone`
- `wrong-character`
- `missed-card`

### 英语表达

- `wrong-meaning`
- `wrong-collocation`
- `wrong-context`
- `missed-target`
- `hint-used`

错误标签用于下一次选择题和提示策略，不用于惩罚。

## 6. 共享结果事件

所有游戏都应发出同样结构的完成事件：

```js
{
  source: "petbank-mini-game",
  version: 2,
  gameId: "pinyin-racer",
  sessionId: "session-...",
  result: "complete",
  completed: 6,
  total: 8,
  mistakes: ["pinyin:..."],
  learning: {
    independentCorrect: 4,
    guidedCorrect: 2,
    hintUses: 1,
    accuracy: 0.75,
    reactionMs: 4200,
    operationErrors: 1
  },
  reward: {
    coins: 12,
    stars: 1
  }
}
```

主站只负责结算奖励；学习记录由小游戏自己的命名空间保存，避免污染主站积分数据。

## 7. 测试设计

### 纯函数测试

- 标准化词卡 ID 不冲突。
- 错误后下次复习时间正确推进。
- 提示后答对不会算作独立正确。
- session 生成优先选择错词和到期词。
- 空词库、重复词卡、损坏的 localStorage 都能回退。

### 浏览器测试

- 开始一局并完成一个目标。
- 输入错误后看到正确答案和重试入口。
- 完成一局后点击复习错题。
- 刷新后恢复当前 session。
- 手机宽度下按钮和题目不重叠。
- 关闭声音或减少动画后仍能理解反馈。
