# 探索地图实施计划

**目标：** 把森林、太空、外星三张地图收束为统一的 RPG 探索层，用每日路线、NPC、学习节点、活动建筑和区域挑战包装小游戏，不复制学习算法。

**代码范围：** `games/explore-map/`、`games/word-memory-map/`、`data/maps-manifest.json`、地图活动配置和专属测试。不得修改各小游戏内部掌握度、题目选择和宿主结算逻辑。

## 步骤

### MAP-P0-01：路线和节点契约

- 增加 `routeId/nodeId/nodeType/cardPolicy/activityId/completionPolicy`。
- 统一 `entry/npc/learn/encounter/activity/resource/checkpoint/portal` 节点。
- 地图使用归一化坐标和配置驱动，不复制三套状态机。

### MAP-P0-02：探索会话和返回上下文

- 保存 `mapId/routeId/currentNodeId/completedNodeIds/learningSessionIds/unclaimedReceiptIds`。
- 活动结束返回原节点、原任务和剩余卡片。
- 刷新后恢复地图状态，不重新随机整条路线。

### MAP-P1-01：森林垂直切片

- 实现入口、学习屋、溪流、单词探险屋、农场、古树检查点。
- 绑定 3 个引导任务、5 个地图任务和一条今日路线。
- 验证学习 -> 资源 -> 播种 -> 离开 -> 回来收获闭环。

### MAP-P2-01：太空和外星差异化

- 太空使用能源、维修机器人、星港训练站和输入活动。
- 外星使用错词、翻译营地、晶体稳定度和补强活动。
- 保持自由进入和推荐路线，不设置不可逆硬锁。

### MAP-P2-02：区域挑战

- 将 Boss 表现为章节/地图检查点。
- 生命值只代表未完成任务，不直接代表掌握度。
- 未达标时生成补强路线，不清空作物或长期资源。

### MAP-P3-01：语法塔和扩展地图预留

- 预留 `english-grammar`/`english-expression` 建筑入口。
- 只有独立内容包存在时才开放语法楼层。
- 天空地图接入拼音赛车时声明 `domain: pinyin`。
