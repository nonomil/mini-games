# 探索地图验收矩阵

| ID | 验收项 | 方法 | 通过标准 |
| --- | --- | --- | --- |
| MAP-A01 | 三张地图配置 | contract test | 森林、太空、外星均有 theme/resource/activity/route |
| MAP-A02 | 节点统一 | route test | 使用同一节点类型和 completionPolicy |
| MAP-A03 | 入口和自由进入 | 手工 | 三张地图都可进入，推荐不是硬锁 |
| MAP-A04 | 森林闭环 | 浏览器 | 探索、学习、奖励、播种、返回收获可完成 |
| MAP-A05 | 活动返回 | 手工/fixture | 小游戏结束回到原 mapId/nodeId/taskId |
| MAP-A06 | 每日路线 | plan fixture | 路线使用到期词/错词/少量新词，不复制题库 |
| MAP-A07 | 区域挑战 | 手工 | 未达标给补强路线，不清空长期资源 |
| MAP-A08 | 跨地图恢复 | resume test | 切换地图、刷新后状态和奖励不丢失 |
| MAP-A09 | 移动端 | 360x800 | 任务、节点、按钮和学习 HUD 不重叠 |
