# 网球学英语实施计划

**目标：** 新建一个短局英语表达游戏，把中文/英文释义、例句或语境变成选择回球，验证 `english-expression` 内容域和主动表达辨析，而不是重复做逐字拼写。

**代码范围：** 新建 `games/tennis-english/`、入口、样式、内容 fixture、manifest 和专属测试。不得修改现有游戏的共享运行时代码。

## 步骤

### TENNIS-P1-01：内容和玩法合同

- 定义表达卡字段：`cardId/expression/definitionEn/definitionZh/example/audio/level/confusionSet`。
- 定义发球、选择、回球、得分、错误反馈和下一球状态。
- 规定游戏分数与表达掌握度隔离。

### TENNIS-P1-02：独立短局 MVP

- 一局 6-8 个表达，控制在 1-3 分钟。
- 场景提示后给出 2-4 个表达选择。
- 支持鼠标、触摸和键盘选择。
- 错误显示搭配/语境原因，允许低难度重试。

### TENNIS-P1-03：结果页和复习

- 记录 `wrong-meaning/wrong-collocation/wrong-context/missed-target/hint-used`。
- 结果页显示表达、错误原因、重练本局错表达和返回入口。
- 不把只看答案或提示后答对记为独立正确。

### TENNIS-P1-04：宿主和内容域

- 清单声明 `contentTypes: ["expression"]`。
- 使用 CORE fixture 验证生命周期。
- 宿主模式只接受表达卡，不读取普通英语词卡的隐含字段。

### TENNIS-P1-05：未来扩展边界

- 为语法之塔预留主题、楼层和章节上下文。
- AI 只能生成解释、例句候选和 NPC 文案，不能生成未经审核的答案。
