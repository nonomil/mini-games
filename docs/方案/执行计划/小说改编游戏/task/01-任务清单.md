## 状态规则

```text
planned -> ready -> in_progress -> review -> verified -> complete
                              \-> blocked
```

`verified` 必须有可复查命令或真实浏览器/宿主证据；只有文档写完或代码写完不能直接标记为 verified。

## 线程边界

- 小说线程只能修改自己的 `games/novel-adventure/`、内容包、工具和专属测试。
- CORE 仍是 `host/`、`bridge.js` 和协议测试的所有者；需要新字段时先提出接口申请。
- MAP 仍是探索地图所有者；小说线程不能直接改地图状态机。
- 小游戏线程不能为小说剧情修改自己的玩法核心。
- 卡片系统线程只负责 adapter 和学习结算，不读取小说私有存档。
