# 飞机大战验收矩阵

| ID | 验收项 | 方法 | 通过标准 |
| --- | --- | --- | --- |
| SHOOTER-A01 | 模式入口正确 | URL/浏览器 | `?game=word-shooter` 可启动飞机模式 |
| SHOOTER-A02 | 移动与输入不冲突 | 手工和键盘测试 | 移动不插入字母，输入不改变方向 |
| SHOOTER-A03 | 主动输入证据 | fixture | 每目标有提示、输入、结果和耗时 |
| SHOOTER-A04 | 漏目标可恢复 | 手工 | 漏目标不直接结束基础局，可补强 |
| SHOOTER-A05 | 错误标签准确 | 测试 | 漏目标、操作错误、拼写错误分开 |
| SHOOTER-A06 | 短局可完成 | 手工 | 基础局 1-3 分钟、6-8 个目标 |
| SHOOTER-A07 | 共享边界稳定 | PINYIN fixture | 拼音线程不修改共享入口即可调用边界 |
| SHOOTER-A08 | 回归测试 | `npm test` | 全局契约不退化 |
