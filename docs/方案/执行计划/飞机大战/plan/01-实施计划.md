# 飞机大战实施计划

**目标：** 把飞机大战变成英语主动输入挑战：玩家锁定目标、输入单词或关键字完成攻击，同时把移动错误、漏目标和英语错误分开记录。

**代码范围：** `games/learning-arcade/game.js` 中飞机模式及其共享运行时、相关样式和专项测试。SHOOTER 是该共享文件的唯一代码所有者；PINYIN 只能在其专属新模块工作。

## 步骤

### SHOOTER-P1-01：模式和共享运行时边界

- 盘点 `word-shooter` 与 `word-cannon` 当前共享的状态、输入、渲染和数据选择。
- 抽出不属于具体游戏的生命周期、卡片和计时接口。
- 写出给 PINYIN 的稳定调用边界。

### SHOOTER-P1-02：移动与字母输入分离

- WASD/方向键只控制移动，字母键只进入输入缓冲。
- 移动端按钮不抢占输入焦点。
- 输入时不因浏览器焦点或按键重复导致重复字符。

### SHOOTER-P1-03：目标和主动输入

- 每局控制在 6-8 个目标。
- 目标显示中文、图片或听音提示，玩家主动输入英文。
- 记录 `missed-target`、`slow-completion`、首字母错误和完整拼写错误。
- 速度只改变操作窗口，不改变学习掌握度。

### SHOOTER-P1-04：错误和阶段结果

- 漏目标时暂停或减速，给出正确答案和重试入口。
- 连续错误降低题型难度，不直接提高速度。
- 结果页提供错题复习、再玩和返回入口。

### SHOOTER-P1-05：协议和回归

- 通过 CORE fixture 发送单卡结果和完成事件。
- 确认 PINYIN 不需要再改共享文件即可读取边界。
- 运行学习机专项测试和全局测试。
