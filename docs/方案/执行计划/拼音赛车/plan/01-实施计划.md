# 拼音赛车实施计划

**目标：** 把当前固定背景、DOM 卡片移动的拼音赛车重构为真正可变化的代码赛道，使用 Canvas 2D 绘制赛道和车辆，同时保留 DOM 学习提示与无障碍入口。

**代码范围：** 拼音专属新模块、拼音数据和测试。当前 `games/learning-arcade/game.js` 由 SHOOTER 独占；在共享边界 `verified` 前不得修改该文件。

## 步骤

### PINYIN-P0-01：内容域和题型定义

- 声明 `domain: pinyin`，区分汉字、原始拼音、标准化拼音和声调。
- 定义听音选拼音、看字选拼音、声母/韵母/声调、输入拼音五种题型。
- 定义 `wrong-initial/wrong-final/wrong-tone/wrong-character/missed-card`。

### PINYIN-P0-02：新运行时边界

- 建立拼音专属 renderer、track model、question model 和测试。
- 提供 `mount/stop/getSnapshot/onCardResult` 形状，不修改共享入口。
- 明确未来由 SHOOTER 共享运行时调用的最小接口。

### PINYIN-P1-01：Canvas 直道 MVP

- 使用 `requestAnimationFrame` 和固定时间步长。
- 赛道坐标使用 `distance/lateral/lane`，不使用 DOM top 值表达车辆位置。
- 先完成直道、车道线、车辆、目标卡和碰撞窗口。
- 固定背景图降级为天空层、缩略图或赛后海报。

### PINYIN-P1-02：复杂赛道

- 增加弯道、S 弯、分叉、坡道、桥、隧道和地标路段数据。
- 赛道由路段配置生成，摄像机随距离推进。
- 车辆、目标和碰撞统一在赛道坐标中计算。

### PINYIN-P1-03：学习时钟和反馈

- 阅读、播放和复习时暂停或减速赛道。
- 错误后显示声母、韵母或声调原因，恢复原卡位置。
- 速度、反应窗口和学习正确率分开统计。

### PINYIN-P2-01：宿主接入

- 清单声明 `domains: ["pinyin"]`。
- 接入 `ready/init/card-result/complete/stop`。
- 只接收拼音卡，不写英语卡片或英语章节进度。

## 统一验收与退出条件

| 阶段 | 必须交付 | 主要证据 | 退出条件 |
| --- | --- | --- | --- |
| P0-01 | 拼音卡字段、题型、错误标签和域隔离 | `tests/test-pinyin-racer.mjs`、fixture 校验 | 冻结的非拼音卡片不能进入拼音 runtime |
| P0-02 | 拼音专属 runtime、track、renderer、snapshot | 专项测试、语法检查、快照恢复 | 独立模块可 mount/stop/恢复，且不改共享入口 |
| P1-01 | Canvas 直道、车辆、目标投影、稳定 viewport 和变道 | race visuals 专项测试、桌面/移动浏览器像素与布局检查 | Canvas 非空、摄像机连续推进、视口无溢出 |
| P1-02 | 配置驱动的弯道、S 弯、分叉、坡道、桥、隧道、地标 | track/config 专项测试、浏览器路线和透视画面 | 路段由代码生成，路线选择可改变并恢复有效赛道 |
| P1-03 | 学习时钟、暂停/减速、碰撞、错误复习和独立 metrics | runtime 专项测试、浏览器交互 | 路线态暂停赛道；语音播放按倍率减速并在结束后恢复；错误复习保持原卡位置 |
| P2-01 | CORE v1 宿主 init/card-result/complete/stop 接线 | 共享入口集成测试和主控验收 | 仅由 SHOOTER/主控确认后落地，fixture 不能替代真实接线 |

### 本轮执行顺序

1. 先完成 P0/P1 专项测试和范围审计，再做浏览器像素、运动和布局验收。
2. 浏览器验收覆盖桌面视口、`390×844` 移动视口和 `360×800` 极窄视口；弹层必须验证答案态、分支态和选择后继续态。
3. 每轮代码变更后执行拼音专项、预集成专项、全局 `npm test` 和 `git diff --check`；只有新鲜输出全部通过，才能更新为 verified。
4. P2 只记录 fixture/preintegration 证据，不把共享入口的真实接线结果归入本线程完成项。
