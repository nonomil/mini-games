# 苦力怕实施计划

**目标：** 把苦力怕稳定为英语逐字拼写训练站，孩子可以看中文、图片或听音主动输入单词，错误可解释、可重试、可进入复习队列。

**代码范围：** `games/typing-defense/web/index.html`、`game.js`、样式和苦力怕专属测试。宿主桥接只调用 CORE 的协议，不在本工作流修改 `host/`。

## 步骤

### CREEPER-P1-01：状态和学习证据盘点

- 标记当前目标选择、输入、敌人接近、命中、失败、结果页状态。
- 找到现有 `hits/misses/learning` 与本地存储写入点。
- 规定每张卡的 `presented/independent-correct/guided-correct/wrong/gave-up` 事件。

### CREEPER-P1-02：标准卡片入口

- 统一英文字段和答案比较规则。
- 独立模式继续使用本地词库；宿主模式只使用 `init.cards`。
- 不把提示后的正确当成独立掌握。

### CREEPER-P1-03：主动输入和错误反馈

- 保留键盘体验，补手机输入方式。
- 记录首个错误位置、删除重输、提示和耗时。
- 错误 2 秒内显示简短原因、正确答案和发音。
- 原题可以低难度重试，不立即结束基础局。

### CREEPER-P1-04：错题复习和结果页

- 结果页展示完成数、首答正确率、提示次数、错词和下次复习时间。
- 支持“复习本局错词”“再玩”“返回入口”。
- 跳过记录为 `gave-up`，不能从任务中消失。

### CREEPER-P1-05：宿主模式和回归

- 使用 CORE fixture 验证 ready/init/card-result/complete/stop。
- 每卡最多发一次结果，刷新可恢复 session。
- 运行专属测试和全局 `npm test`。
