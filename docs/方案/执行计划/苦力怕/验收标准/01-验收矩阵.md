# 苦力怕验收矩阵

| ID | 验收项 | 方法 | 通过标准 |
| --- | --- | --- | --- |
| CREEPER-A01 | 独立入口可玩 | 浏览器 | 30 秒内开始第一题，完成一局 |
| CREEPER-A02 | 宿主卡片不被替换 | fixture | 初始化的卡片和顺序被使用 |
| CREEPER-A03 | 主动输入记录 | 测试/手工 | 首答、耗时、提示、错误位置均可读取 |
| CREEPER-A04 | 错误反馈 | 手工 | 2 秒内说明错误并展示正确答案/发音 |
| CREEPER-A05 | 原题重试 | 手工 | 答错后可低难度重试，基础局不立即结束 |
| CREEPER-A06 | 错词出口 | 手工 | 结果页可只复习本局错词 |
| CREEPER-A07 | 结果幂等 | contract test | 每张卡最多一个 `card-result` |
| CREEPER-A08 | 手机输入 | 360x800 | 输入框、键盘和反馈不遮挡 |
| CREEPER-A09 | 回归 | `npm test` | 全局契约通过 |
