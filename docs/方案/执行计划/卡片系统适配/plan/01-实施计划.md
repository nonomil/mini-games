# 卡片系统适配实施计划

**目标：** 让卡片式单词学习游戏记忆系统可以把当前小游戏作为章节阶段调用，接收标准结果，写入学习事件、复习计划和奖励 receipt，并把用户带回原章节或探索节点。

**项目范围：** `G:\StudyCode\卡片式单词学习游戏记忆系统`。重点检查 `js/games/full-game-adapter.js`、`word-quest-host`、`word-quest-game-bridge`、章节 `gamePolicy`、session/progress/rewards 测试。

## 步骤

### ADAPTER-P0-01：现有适配器盘点

- 读取 `createGameLifecycle()`、`createFullGameAdapter()` 和现有 iframe 消息。
- 对照 CORE 协议列出兼容字段、别名和版本策略。
- 不修改现有章节阈值和 Profile 规则。

### ADAPTER-P1-01：外部游戏清单和 URL

- 增加 `sourceGame`、`gameVersion`、`entryUrl` 和能力声明。
- 苦力怕、飞机大战先接英语输入阶段。
- 拼音赛车只进入 `pinyin` 章节，网球进入 `english-expression` 路由。

### ADAPTER-P1-02：payload 和结果归一化

- 将章节 10 张卡转换为宿主 payload，不重新随机。
- 将标准 `card-result` 转为现有 `word-quest-progress` 事件。
- 保留 `independent/guided/hint/responseMs/errorTags`。

### ADAPTER-P1-03：章节和地图返回

- 保存章节 session、returnContext、gameId 和节点信息。
- 停止/刷新/完成后回到原章节或地图。
- 游戏不能自行解锁章节或发放 Profile 奖励。

### ADAPTER-P2-01：成长和 AI 接口边界

- 将 XP、等级、连胜和勋章接入既有 rewards receipt。
- 今日计划和 AI 教练只在卡片系统调度。
- AI 失败不阻塞游戏和复习计划。

### ADAPTER-P2-02：跨项目回归

- 运行卡片系统 `npm test`。
- 覆盖 adapter、生命周期、重复消息、刷新、替换游戏和 domain 路由。
