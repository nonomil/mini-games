# 跨游戏底座验收矩阵

| ID | 验收项 | 方法 | 通过标准 |
| --- | --- | --- | --- |
| CORE-A01 | 清单完整 | 读取 manifest | 每个游戏有稳定 `gameId`、domain/capabilities 和入口 |
| CORE-A02 | 卡片稳定 | fixture 测试 | 原始 `cardId` 不被游戏重新生成 |
| CORE-A03 | 生命周期完整 | contract test | `ready/init/card-result/complete/stop` 顺序可完成 |
| CORE-A04 | 结果幂等 | 重复消息测试 | 相同卡片重复提交只接受一次 |
| CORE-A05 | 消息安全 | origin/session 测试 | 未知来源或 session 被拒绝 |
| CORE-A06 | 停止清理 | lifecycle test | 计时器、事件、动画和语音停止 |
| CORE-A07 | 刷新恢复 | session fixture | 能恢复相同 session，不随机换题 |
| CORE-A08 | 独立兼容 | `npm test` | 现有契约和完整内容测试全部通过 |

## 不通过即退回

- 游戏直接 import 卡片系统源码。
- 游戏直接写 Profile、章节、FSRS 或长期奖励。
- `complete` 事件等同于章节完成。
- 使用 `*` origin 且没有生产环境替换方案。
