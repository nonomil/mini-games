# 任务分配矩阵

## 1. 线程分配

| 线程代号 | 工作流 | 项目 | 首个交付物 | 允许修改 | 不允许修改 |
| --- | --- | --- | --- | --- | --- |
| CORE | 跨游戏底座 | 小游戏项目 | manifest、消息协议和契约测试 | `host/`、`bridge.js`、共享测试、接口文档 | 各游戏业务玩法 |
| CREEPER | 苦力怕 | 小游戏项目 | 苦力怕独立模式学习闭环 | `games/typing-defense/web/`、专属测试 | `games/learning-arcade/`、宿主核心 |
| SHOOTER | 飞机大战 | 小游戏项目 | 共享运行时边界和飞机模式输入分离 | `games/learning-arcade/`、专属测试 | 苦力怕、拼音专属新模块 |
| PINYIN | 拼音赛车 | 小游戏项目 | 拼音题型与 Canvas 赛道设计/实现 | 拼音专属模块、拼音数据、专属测试 | SHOOTER 所有权文件，英语词卡 |
| TENNIS | 网球学英语 | 小游戏项目 | 独立可玩的表达选择 MVP | `games/tennis-english/`、专属测试 | 其他游戏和共享桥接实现 |
| MAP | 探索地图 | 小游戏项目 | 森林探索路线和返回上下文 | `games/explore-map/`、`games/word-memory-map/`、地图配置 | 游戏内部学习算法、Profile |
| ADAPTER | 卡片系统适配 | 卡片系统项目 | 外部游戏 adapter、fixture 和生命周期测试 | `js/games/`、adapter 测试、卡片系统方案 | 小游戏源代码、掌握度规则的破坏性修改 |

## 2. 依赖矩阵

| 任务 | 依赖 | 可否并行 | 主控检查点 |
| --- | --- | --- | --- |
| CORE-P0 | 无 | 是 | 协议字段和重复结果测试 |
| CREEPER-P1 | CORE 字段草案 | 是 | 独立模式先完成，不等待宿主 |
| SHOOTER-P1 | CORE 字段草案 | 是 | 先锁定 `learning-arcade` 共享边界 |
| PINYIN-P0 | 读取 SHOOTER 运行时边界 | 方案可并行，代码后置 | 不得修改共享文件 |
| TENNIS-P1 | CORE 字段草案 | 是 | 新目录，不影响现有入口 |
| MAP-P1 | CORE 返回协议草案 | 是 | 地图只管上下文和世界变化 |
| ADAPTER-P2 | CORE ready/init/card-result 协议验证 | 可并行做 fixture，接入后置 | 卡片系统只结算宿主结果 |

