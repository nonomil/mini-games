# 小游戏项目 v0.2.0

发布日期：2026-07-29

这是独立发布的完整小游戏项目，提供完整探险地图、游乐场全部玩法、全部词库和宠物卡牌。它与单词远征的区别是：本项目直接开放完整内容，不按学习阶段切分。本版本是一次功能型小版本升级，统一了多个游戏入口、学习反馈和地图内容的发布边界。

## 本版本包含

- 数学冒险独立入口，覆盖加法、乘法、每日随机 PK 和机器人挑战的分层流程。
- 网球学英语 MVP，使用英语表达卡、语境判断、反馈和复习出口组织短局学习。
- 森林路线、农场/太空/外星地图的 manifest 和内容入口整理，保持地图资源可校验、可复现。
- 拼音星际巡航、英语输入防守和共享游乐场的学习状态、暂停、错误反馈与结果事件增强。
- 跨游戏生命周期协议、主站启动参数、完成事件和契约测试补齐，游戏可以独立运行也可以被主站启动。
- 首页、移动端入口、Windows 一键启动脚本、完整内容看板和版本徽标同步更新。

## 发布与验证

```powershell
npm test
npm run build:static
```

`npm test` 覆盖共享契约、数学冒险、地图探索、完整内容、网球英语和运行时契约；静态构建用于检查 GitHub Pages 发布目录。

## 版本边界

- 项目版本：`0.2.0`，用于标识本次可发布的功能集合。
- 跨游戏协议版本：继续保持现有协议语义，避免把项目发布升级误当成协议破坏性升级。
- 词库、故事和地图内容包各自保留自己的内容版本；内容包更新不直接修改项目版本规则。
- AI 教练、完整 RPG 探索地图和更复杂的个体化复习属于后续阶段，当前版本使用本地确定性流程保证离线可玩。

本地启动：双击 `启动小游戏项目.bat`。
