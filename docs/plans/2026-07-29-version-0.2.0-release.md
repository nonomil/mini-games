## 风险与回滚

- 任一批次测试失败时停止推送，保留已推送的前序快进提交，不回退远程历史。
- 不使用 `git push --force`、`reset --hard` 或删除用户目录。
- 发现资源路径删除时，先恢复远程 tree 条目，再继续提交。
- 协议字段版本与项目版本冲突时，优先保持协议兼容，单独记录迁移说明。
